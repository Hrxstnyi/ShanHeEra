## 二、外貌描写

### 整体形象
身高一米七五，皮肤黝黑（长年在海上跑的缘故），身材精瘦但结实。走路时步子很大，像在船上走惯了甲板。他的眼神总是望着海的方向，像是在看什么，又像是什么都没看。

### 面部
- 国字脸，浓眉，眼睛很亮，带着海水洗过的清澈
- 嘴角总是带着一点温和的笑，但笑里有一丝忧愁
- 右手有一道长长的疤，从手腕到肘部（海难时被船缆割的）
- 常年被海风吹，皮肤粗糙，但手很干净（他说"手干净，心才干净"）

### 穿着
- 蓝色短打，外面罩一件青色长衫（上岸时穿，在船上就脱了）
- 腰间系着一条红色的腰带（他母亲给他做的，说红色能保平安）
- 脚上是草鞋（在船上穿），上岸了换布鞋
- 脖子上挂着一个小小的妈祖像吊坠（渔民的信仰）

### 标志性物品
- **船票**：一张泛黄的船票，是他父亲从福建到台湾的船票，他一直带在身上
- **妈祖像**：脖子上的吊坠，每次出海前都会摸一下
- **航海图**：一张手绘的航海图，上面标注着从台湾到大陆各个港口的航线，密密麻麻的

## 三、性格特质

### 核心性格：温和坚定 + 家国情怀

| 表面 | 内里 |
|------|------|
| 温和有礼，说话轻声细语 | 信念极其坚定，不可动摇 |
| 商人，精于计算 | 在大是大非面前不计较利益 |
| 看起来像个普通的海商 | 心里装着两岸的百姓 |
| 总是笑着 | 笑里藏着对分离的忧愁 |
| 不参与政治 | 用商业的方式做着政治做不到的事 |

### 性格细节

**温和的一面：**
- 对船员很好，从不打骂，有难同当
- 做生意公道，不欺不瞒，两岸的商人都信任他
- 看到小孩会给糖，看到老人会让座
- 说话时会看着对方的眼睛，很真诚

**坚定的一面：**
- 有人说台湾不是中国的，他会立刻翻脸，"你可以说我不好，但不能说我的家不好"
- 海禁最严的时候，别人都不敢跑船了，他还在跑，"这海不能断，断了，两岸的人就断了联系"
- 外敌觊觎台湾时，他第一个站出来组织民防，"这是我们的家，谁也别想拿走"

### 口头禅
- "回家。"（他说的"家"有时候指台湾，有时候指大陆，看语境）
- "这海啊，说宽也宽，说窄也窄。"
- "都是中国人，说什么两家话。"
- "我父亲说过……"（经常引用父亲的话）
- （认真时）"有些事，总得有人做。我不做，别人也会做，但我等不及了。"

## 四、背景故事

### 家族史
陈志华的祖上是福建泉州人，康熙年间迁台。到他这一代，已经是第四代了。但他的家族一直保留着福建的习俗、方言、信仰。他从小就听父亲说"我们的根在大陆"。

父亲是个海商，在他十五岁那年，因为海禁，船被官府扣了，父亲一气之下病了，没多久就去世了。临终前对他说"华儿，这海，不能断。"

### 他的事业
陈志华十六岁接过父亲的船，继续跑两岸贸易。海禁严的时候，他就走私（他不觉得这是走私，"这是回家的路"）。他的船不运奢侈品，只运粮食、布匹、药材、书籍——都是两岸百姓需要的东西。

他在台湾府开了个商行叫"思远号"，意思是"思念远方"。在大陆的泉州、福州、广州都有联络点。

### 他的信念
他不是官员，不是将军，他只是个商人。但他用自己的方式维护着两岸的联系：
- 海禁时，他的船是两岸唯一的联系
- 灾年时，他从大陆运粮到台湾，或从台湾运粮到大陆
- 他资助两岸的学子，让台湾的学生能到大陆读书
- 他在台湾建了个祠堂，供奉的是福建的祖先

他常说："当官的可以说断就断，但老百姓的日子不能断。我跑我的船，他们过他们的日子，这就够了。"

### 隐藏线
- 他的商行其实是两岸情报网的一部分（和陆九的听雨楼有联系）
- 他在暗中帮助台湾的居民抵抗外来势力的渗透
- 他有一个女儿，在大陆读书（这条线可以延伸到下一代）

- 台湾暗喻线的入口

## 六、对话风格示例

### 日常

> **玩家**：陈老板，这趟去大陆赚了不少吧？
>
> **陈志华**：（笑）赚什么钱啊，不赔就不错了。这趟运了三十石粮食，台湾今年歉收，百姓等着吃呢。
>
> **玩家**：那您图什么？
>
> **陈志华**：（望着海的方向）图什么……我父亲说过，人活着，不能只图钱。这海两边都是人，都是一家人。我跑一趟，两边的人都能过好日子，这就值了。

> **玩家**：陈老板，您觉得台湾和大陆是什么关系？
>
> **陈志华**：（从怀里掏出那张泛黄的船票）你看这个。这是我父亲来台湾的船票。他从泉州上船，到台湾下船。你说，上船的地方和下船的地方，是什么关系？
>
> **玩家**：……一条路的两头？
>
> **陈志华**：（笑）对。一条路的两头。路可能会断，但两头的人，永远是一家人。

### 关键时刻

> **场景**：外敌舰队逼近台湾，人心惶惶。
>
> **居民**：陈老板，怎么办？官兵都跑了！
>
> **陈志华**：（站在港口，声音不大但所有人都能听见）官兵跑了，我们不跑。这是我们的家。
>
> **居民**：可我们打不过他们啊！
>
> **陈志华**：打不过也要打。我父亲说过，有些东西，比命重要。（转身对自己的船员）把船上的货都卸了，装石头。我们的船，就是炮台。
>
> **居民**：（沉默了一会儿，然后有人喊）跟陈老板干了！
>
> （越来越多的人加入，最终击退了外敌）

> **场景**：玩家帮助陈志华完成了两岸通商，海禁开放。
>
> **陈志华**：（站在船头，看着大陆的方向，眼眶红了）父亲，您看到了吗？这海，没断。
>
> **玩家**：陈老板，您哭了？
>
> **陈志华**：（擦了擦眼睛，笑）海风太大，迷了眼。（顿了顿）谢谢你。这件事，我一个人做不到。

## 七、个人任务线（台湾暗喻线核心）

### 任务一：《思远号》
- 玩家在泉州遇到陈志华，他的船被扣了
- 玩家帮他要回船，他邀请玩家一起去台湾
- 第一次踏上台湾，玩家发现这里和大陆同文同种

### 任务二：《海禁》
- 朝廷下了海禁令，两岸贸易中断
- 陈志华决定冒险跑船，玩家可以选择加入
- 途中遇到风暴、海盗、官府追兵
- 最终把粮食送到了台湾灾民手中

### 任务三：《同文同种》
- 玩家在台湾生活一段时间，发现这里的节日、习俗、信仰都和大陆一样
- 陈志华带玩家去看他建的祠堂，供奉的是福建的祖先
- "你看，我们拜的是同一个祖先，过的是同一个节，说的是同一种话。这不是一家人是什么？"

### 任务四：《守土》
- 外敌觊觎台湾，试图渗透和侵略
- 陈志华组织民防，玩家协助
- 最终击退外敌，保卫了台湾
- 陈志华说："这土地，是我们的祖先传下来的。谁也别想拿走。"

### 任务五：《海波平》
- 最终任务：玩家和陈志华一起推动朝廷开放海禁
- 两岸恢复正常贸易和往来
- 陈志华站在船头，看着两岸的船只来来往往
- "父亲，您看到了吗？海波平了。"
- 触发CG《海波平》，配乐温暖而感动

## 八、角色弧光

```
初期：继承父亲遗志 → 独自跑船 → 一个人维护两岸联系
  ↓
中期：遇到玩家 → 不再孤单 → 力量壮大
  ↓
后期：面对外敌 → 组织民众 → 证明人民的力量
  ↓
终章：海禁开放 → 两岸恢复联系 → 完成父亲的遗愿
```

**核心主题**：一个普通人，用自己的方式维护着国家的统一。他不是将军，不是官员，但他做的事比很多官员都重要。台湾是中国不可分割的领土——不是因为条约，不是因为武力，而是因为两岸的人民，从来就是一家人。
