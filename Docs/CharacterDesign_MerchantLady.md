# 沈婉清 — 江南女商 完整人设

## 外貌描写

- 身材纤细，穿月白褙子，腰间系一条银鼠皮裙
- 鹅蛋脸，柳叶眉，眼睛很亮，笑起来有两个酒窝
- 平时梳简单的垂鬟分肖髻，只插一支玉簪
- 手指纤细但有薄茧（常年打算盘）
- 说话语速不快，但每个字都很清楚，带着江南口音
- 生气时不骂人，只是把算盘打得噼啪响

## 性格核心

**精明强干 + 外柔内刚 + 商业奇才 + 家国情怀**

- **精于算计**：对数字极度敏感，过目不忘，能在心里算清一笔账的所有细节
- **外柔内刚**：表面温婉，实际上极有主见，认定的事九头牛拉不回
- **重信重义**：做生意讲诚信，但对背信弃义的人绝不手软
- **有大局观**：不只是赚钱，她明白"商通有无，民得其利"的道理
- **隐藏的家国情怀**：表面只谈生意，但在大是大非面前会毫不犹豫地站出来
- **成长弧光**：从"我要把沈家商号发扬光大"的商人，到"以商救国"的实业家

## 背景故事

沈婉清是江南沈家的独女。沈家三代经营丝绸生意，到她父亲这一代已经是江南数一数二的大商号。

她12岁开始跟着父亲学做生意，15岁就能独立打理一个分号。17岁那年父亲病逝，族中长辈以为她一个女孩子撑不起家业，想瓜分沈家财产。她用三年时间，以雷霆手段整顿商号，不仅稳住了局面，还把生意扩大了三倍。

19岁，她已经是江南商界无人不知的"沈大姑娘"。但她并不满足——她看到海禁导致沿海百姓生计艰难，看到贪官污吏盘剥商人，看到外国商人在东南沿海横行。她想做更大的事。

## 五段任务线

### 第一段：初遇（19岁）
- **触发**：玩家在江南市集遇到正在与牙人讨价还价的沈婉清
- **内容**：沈婉清发现一批丝绸被人以次充好，玩家可以选择帮她鉴别或帮牙人说话
- **选择影响**：帮她 → 好感+20，她给玩家一张商号的折扣帖；帮牙人 → 她冷笑一声自己解决，以后对玩家冷淡
- **关键对话**："这匹绸子的经纬密度不对，你当我看不出来？做生意，讲究的是一个'诚'字。"

### 第二段：商战（21岁）
- **触发**：好感>40，沈婉清请玩家帮忙
- **内容**：沈家商号遭遇竞争对手联合打压，价格战、挖人、断货源，三管齐下
- **玩家任务**：帮她调查对手的底牌、寻找新的货源、在关键时刻截胡对手的大单
- **高潮**：一场丝绸拍卖会上，玩家和沈婉清联手，以退为进，让对手高价吃下一批烂货
- **关键对话**："做生意就像下棋，你看到的是眼前这一步，我看到的是十步之后。"

### 第三段：开海禁（24岁）
- **触发**：好感>60，沈婉清提出一个大胆的计划
- **内容**：沈婉清想推动朝廷开放海禁，发展海上贸易。这需要打通朝堂、地方、海防三层关系
- **玩家任务**：
  - 帮她联络沿海渔民和商人（收集民意）
  - 帮她贿赂/说服朝中官员（官场线）
  - 帮她对付海盗（战斗线/江湖线）
- **高潮**：朝廷终于开放部分港口，沈婉清的船队第一次出海
- **关键对话**："海禁禁的不是海盗，是百姓的活路。开了海，渔民有鱼打，商人有货卖，朝廷有税收，何乐而不为？"

### 第四段：以商救国（28岁）
- **触发**：第三段完成，且国家处于危机（战争/天灾）
- **内容**：国家遭遇危机，国库空虚，朝廷无力应对。沈婉清提出"以商救国"——用商人的力量支持国家
- **玩家任务**：
  - 帮她组织商人捐款捐粮
  - 帮她打通后勤补给线（战争时）
  - 帮她在灾年平价售粮（天灾时）
- **高潮**：沈婉清以一己之力，组织江南商人支援前线/灾区，成为一段佳话
- **关键对话**："商人逐利没错，但君子爱财取之有道。国家有难，匹夫有责，何况我沈婉清？"

### 第五段：商通天下（32岁）
- **触发**：前四段完成
- **内容**：沈婉清的商号已经成为全国最大，她想做一件前人没做过的事——建立全国性的商业网络
- **玩家选择**：
  - 支持她 → 建立"商盟"，统一度量衡和货币兑换，商业繁荣
  - 劝她适可而止 → 她守住江南，成为一代传奇
  - 与她合作 → 玩家成为商盟二把手，富可敌国
- **关键对话**："我这辈子没别的志向，就是想让天下的生意人，都能堂堂正正地赚钱，让天下的百姓，都能买到好东西。"

## 玩家互动

- 可以跟她学做生意（商业技能线）
- 可以加入她的商号走商人路线
- 可以和她合作开海禁（航海线）
- 她是爱国彩蛋"扬帆远航"（郑和下西洋）和"人民团结"的关键触发角色
- 她是台湾暗喻线的重要资助者

## 特殊机制：商业谈判

与沈婉清相关的交易有特殊的"谈判"小游戏：
- 玩家可以出价，她会还价
- 根据玩家的商业技能和好感度，她的底线会变化
- 谈判成功可以获得更优惠的价格或独家商品
- 谈判失败她会生气，但不会记仇（"生意不成仁义在"）
