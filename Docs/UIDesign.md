# 山河纪元 · UI/UX 设计文档

> 界面不是装饰。界面是玩家与历史之间的桥梁。

---

## 一、设计原则

### 核心原则
1. **信息差可视化**：不同身份/层级的玩家看到的信息不同，界面要体现这种不对称
2. **国风美学**：水墨、卷轴、印章、宣纸质感，但不堆砌元素
3. **信息密度可控**：战略层信息密集，人生层信息简洁，战斗层信息聚焦
4. **少即是多**：日常界面只显示最必要的信息，详细信息需要主动查看

### 视觉风格
- **主色调**：墨黑 + 宣纸米白 + 朱砂红（强调色）+ 青金石蓝（信息色）
- **字体**：标题用书法体，正文用宋体/明体，数字用等宽字体
- **动效**：卷轴展开、墨迹晕染、印章盖下——所有转场都有国风韵味
- **图标**：线性描边风格，类似古代篆刻

## 二、三层模式界面架构

### 2.1 个人人生层（太吾式）

```
┌─────────────────────────────────────────────────┐
│  [日期]  洪武三年 · 春 · 三月初七    [时辰] 巳时  │  ← 顶部状态栏
├─────────────────────────────────────────────────┤
│                                                 │
│                                                 │
│              游戏世界画面（第三人称）              │
│                                                 │
│                                                 │
├─────────────────────────────────────────────────┤
│ [体力] [饱腹] [心情]  [银两: 123]  [声望: 45]    │  ← 底部状态条
│ [背包] [技能] [家族] [日程] [地图] [系统]         │  ← 功能按钮
└─────────────────────────────────────────────────┘
```

**特点：**
- 信息简洁，聚焦玩家个人状态
- 顶部只显示日期和时辰（农民不知道朝廷发生了什么）
- 底部是体力/饱腹/心情等个人属性
- 功能按钮用图标+文字，点击展开卷轴式面板

**信息差表现：**
- 农民玩家的地图只显示去过的地方，没去过的是迷雾
- 朝廷大事只能通过"听说"获得，且可能不准确
- 粮价变化只显示本地价格，不知道全国行情

### 2.2 大地图战略层（CK3式）

```
┌──────────────────────────────────────────────────────┐
│ [年份] 洪武三年  [国库: 120万] [天下安定: 65%] [暂停]│  ← 顶部战略栏
├──────┬───────────────────────────────────────────────┤
│      │                                               │
│ 角色  │                                               │
│ 列表  │              全国大地图                         │
│      │        (省份/城市/军队/事件标记)                 │
│ 派系  │                                               │
│ 列表  │                                               │
│      │                                               │
├──────┴───────────────────────────────────────────────┤
│ [选中城市详情] 人口/经济/驻军/太守/稳定度              │  ← 底部详情面板
└──────────────────────────────────────────────────────┘
```

**特点：**
- 信息密集，全局视角
- 左侧是角色/派系列表（CK3风格）
- 中央大地图，可缩放平移
- 底部显示选中对象的详细信息
- 支持时间控制：暂停/1x/3x/快速

**信息差表现：**
- 高官玩家能看到全国数据，但看不到具体村庄的细节
- 远方省份的信息有延迟（"据上月奏报..."）
- 敌国信息不完全，需要情报系统

### 2.3 战场战术层（骑砍式）

```
┌─────────────────────────────────────────────────┐
│  [战役名] 洛阳之战      [我军: 12000] [敌军: 15000] │  ← 顶部战斗栏
├─────────────────────────────────────────────────┤
│                                                 │
│              战场画面（第三人称/可切指挥）          │
│        (部队旗帜、地形、冲锋路线、士气条)            │
│                                                 │
├─────────────────────────────────────────────────┤
│ [我军士气] ████████░░ 78%   [敌军士气] █████░░░░ 52% │
│ [冲锋] [防守] [撤退] [重整]   [部队列表]            │  ← 底部指挥栏
└─────────────────────────────────────────────────┘
```

**特点：**
- 玩家可亲自上阵（第三人称砍杀）或切到指挥视角
- 顶部显示双方兵力对比
- 底部是指挥按钮和部队列表
- 士气条实时变化，溃逃时会闪烁警告

## 三、核心界面设计

### 3.1 主菜单

```
┌─────────────────────────────────────────────────┐
│                                                 │
│              山 河 纪 元                         │
│         华夏古代历史文明沙盘                      │
│                                                 │
│           "历史不是背景"                          │
│           "历史就是世界本身"                      │
│                                                 │
│           [ 新的人生 ]                           │
│           [ 继续游戏 ]                           │
│           [ 设  置 ]                            │
│           [ 退  出 ]                            │
│                                                 │
│         语言: [中文 ▼]    版本 1.0.0             │
└─────────────────────────────────────────────────┘
```

- 背景是动态水墨山河图，随时间缓慢变化
- 标题用书法字体，有墨迹晕染效果
- 按钮是卷轴样式，hover时展开
- 右下角语言切换（中/英/日）

### 3.2 角色创建（出生选择）

```
┌─────────────────────────────────────────────────┐
│  第一步：选择时代                                 │
│  ○ 盛世  ○ 中兴  ● 乱世前夕  ○ 战争  ○ 改朝换代   │
│                                                 │
│  第二步：选择地域                                 │
│  [北方平原] [江南水乡] [西北边疆] [西南山区]       │
│  [东南沿海] [中原腹地] [东南海岛]                  │
│                                                 │
│  第三步：选择家庭                                 │
│  [贫困农户] [普通家庭] [小商之家] [工匠之家]       │
│  [书香门第] [官宦之家] [富商之家]                  │
│                                                 │
│  第四步：命名 + 初始属性                          │
│  姓名: [________]  字: [____]                    │
│  武力: ████░░  智力: █████░  魅力: ███░░          │
│                                                 │
│              [ 踏入红尘 ]                         │
└─────────────────────────────────────────────────┘
```

- 每一步都有详细说明，包括初始条件和难度
- 属性点分配，总点数固定，玩家自由分配
- 地域选择时显示该地区的特色和难度

### 3.3 HUD（人生层）

**顶部状态栏：**
- 左：日期 + 季节 + 时辰
- 中：当前所在地
- 右：小地图（可展开）

**底部状态条：**
- 左：体力/饱腹/健康/心情（四个图标+进度条）
- 中：银两/铜钱
- 右：声望/官位（如果有）

**快捷栏：**
- 数字键1-8对应物品/技能
- 滚轮切换

### 3.4 信息传播界面（信息差核心）

当玩家获取一条信息时，显示信息卡片：

```
┌─────────────────────────────────┐
│  📜 听说                         │
├─────────────────────────────────┤
│  据来往客商说，京城最近出了大事，  │
│  好像是有大臣被革职了……            │
│                                 │
│  来源：商旅传闻                   │
│  可信度：★★★☆☆ (60%)           │
│  传播延迟：约15天前的事           │
│                                 │
│  [ 记入笔记 ]  [ 忽略 ]           │
└─────────────────────────────────┘
```

- 信息卡片用宣纸卷轴样式
- 显示来源、可信度、传播延迟
- 可信度低的信息文字会模糊或有错字
- 玩家可以记入笔记，后续验证真伪

## 四、交互设计

### 4.1 鼠标操作
- **左键**：确认/交互/攻击
- **右键**：取消/返回/格挡（战斗中）
- **滚轮**：缩放地图/切换快捷栏
- **中键拖拽**：平移大地图

### 4.2 键盘操作
| 按键 | 功能 |
|------|------|
| WASD | 移动 |
| E | 交互 |
| Tab | 打开/关闭菜单 |
| I | 背包 |
| K | 技能 |
| M | 地图 |
| J | 任务/日程 |
| 空格 | 跳跃/确认 |
| Esc | 暂停/返回 |
| 1-8 | 快捷栏 |
| F5/F9 | 快速存档/读档 |

### 4.3 手柄支持
- 左摇杆移动，右摇杆视角
- A确认，B取消
- X交互，Y跳跃
- LB/RB切换页面
- LT/RT格挡/攻击
- Start暂停，Select地图

## 五、音效与反馈

### UI音效
- 按钮点击：木质敲击（轻）
- 打开面板：竹简展开声
- 确认：玉佩碰撞
- 取消：古琴泛音
- 错误：低沉锣声
- 获得成就：编钟一响

### 视觉反馈
- 重要事件：屏幕边缘泛红（战争）/泛金（喜庆）
- 获得物品：物品图标从屏幕中央飞入背包
- 升级：属性数字跳动+光芒
- 时间流逝：光影缓慢变化（白天/黄昏/夜晚）

---

## 六、响应式布局

- **最低分辨率**：1280x720
- **推荐分辨率**：1920x1080
- **超宽屏**：21:9支持，大地图更宽
- **UI缩放**：支持0.5x-2x缩放，适配不同屏幕

---

## 七、无障碍设计

- 文字大小可调（小/中/大/特大）
- 颜色blind模式（替代颜色编码为图标+文字）
- 字幕开关（所有语音都有字幕）
- 键位完全自定义
- 简化模式（减少操作复杂度，适合休闲玩家）

---

*界面的最高境界，是让玩家忘记界面的存在。*
