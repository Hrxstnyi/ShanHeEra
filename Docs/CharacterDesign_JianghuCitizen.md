# 江湖市井角色群像 — 神医/歌姬/富商完整人设

## 一、神医：孙思邈（化名孙妙手）

### 基本信息
| 项目 | 内容 |
|------|------|
| 姓名 | 孙妙手（化名，真实身份是孙思邈的传人） |
| 年龄 | 出场60岁 |
| 身份 | 游方郎中，医术通神 |
| 性格标签 | 怪癖、慈悲、嗜酒、大智若愚 |

### 外貌
- 瘦小枯干，像个干巴老头
- 头发花白，挽成一个道髻，插一根木簪
- 眼睛很小，但很亮，像能看穿人的五脏六腑
- 穿一件洗得发白的青布道袍，腰间挂个葫芦
- 走路有点跛（年轻时行医摔的），但走得很快
- 身上永远有一股药味和酒味混合的奇怪气味

### 性格核心
**看似疯癫的外表下，是一颗医者仁心**
- 怪癖：给人看病先看对方有没有钱，没钱的免费治，有钱的往死里宰
- 慈悲：遇到穷人看病，不仅不收钱，还倒贴药钱
- 嗜酒：每天必喝，喝醉了反而医术更高
- 大智若愚：经常说一些疯话，但事后证明都是对的
- 有原则：不治三种人——贪官、汉奸、忘恩负义之徒

### 背景故事
孙妙手出身医学世家，祖上是孙思邈的传人。他年轻时在太医院当差，因为看不惯太医们的官僚作风，辞官云游四方。

他的医术已经到了"起死回生"的境界——据说曾让一个断气三天的人活过来。但他从不炫耀，反而经常装成庸医，试探求医者的人品。

他云游四方，一边治病救人，一边收集民间药方，想写一本比《千金方》更全的医书。

### 五段任务线

#### 第一段：怪医初遇
- **触发**：玩家或队友生病，在县城遇到孙妙手
- **内容**：孙妙手故意开错药方试探玩家，如果玩家质疑他，他会大笑并承认真实身份
- **选择**：信任他 → 好感+20，免费治病；质疑他 → 他考验玩家的医学知识，通过后好感+30
- **关键对话**："你这病，三分治七分养。我开的药你敢吃吗？不敢吃就别找我。"

#### 第二段：瘟疫横行
- **触发**：疫病事件发生时，孙妙手出现在疫区
- **内容**：孙妙手在疫区免费治病，但人手不够，玩家需要帮他采药、隔离病人、熬药
- **高潮**：疫病失控，孙妙手决定用自己试药，玩家需要阻止他或帮他找到替代方案
- **关键对话**："我这把老骨头，能换几百条人命，值了。"

#### 第三段：医书传承
- **触发**：好感>60，孙妙手邀请玩家去他的隐居处
- **内容**：孙妙手的医书写了一半，但他知道自己时日无多，想找传人
- **玩家任务**：帮他整理药方、验证药效、补充缺失的部分
- **选择**：成为他的传人（解锁医学大师路线）或帮他找其他传人
- **关键对话**："医术这东西，藏在柜子里就是废纸，用在人身上才是活的。"

#### 第四段：宫廷之争
- **触发**：皇帝生病，朝廷征召孙妙手入宫
- **内容**：孙妙手不想卷入宫廷斗争，但皇帝的病只有他能治
- **玩家任务**：保护孙妙手的安全，帮他在宫廷倾轧中自保
- **高潮**：有人想借皇帝的病陷害孙妙手，玩家需要找出真凶
- **关键对话**："我治得了身体的病，治不了人心的病。这宫里，病人比病人还多。"

#### 第五段：医者归处
- **触发**：前四段完成
- **内容**：孙妙手的医书终于完成，但他的身体也到了极限
- **结局分支**：
  - 他在一个小村庄安详去世，医书流传后世
  - 他用最后一口气救了一个瘟疫中的孩子，含笑而终
  - 玩家如果医学技能足够高，可以用特殊药方延续他的生命
- **关键对话**："我这辈子，治过几万人，有好人有坏人。到最后才明白，最好的药不是草药，是人心。"

### 经典台词
1. "治病先治心，心不正，药不灵。"
2. "我这葫芦里的酒，比太医院的药还灵。"
3. "阎王要你三更死，我偏留你到五更——前提是你付得起诊金。"
4. "天下的病，一半是吃出来的，一半是气出来的。"
5. "我死了以后，把我烧了，骨灰撒进河里，让鱼也尝尝我的医术。"

### 与其他角色的关系
- **苏忘机**：两人是酒友，经常一起喝酒吹牛，苏忘机叫他"孙酒鬼"
- **霍青云**：霍青云的伤是孙妙手治好的，两人是忘年交
- **沈婉清**：沈婉清的商号帮孙妙手采购药材，孙妙手给沈家的人免费看病
- **陈志华**：孙妙手曾去台湾行医，是陈志华的老朋友

## 二、歌姬：柳如是（化名柳如烟）

### 基本信息
| 项目 | 内容 |
|------|------|
| 姓名 | 柳如烟（化名，真实名字柳如是） |
| 年龄 | 出场20岁 |
| 身份 | 江南第一名妓，秦淮八艳之首 |
| 性格标签 | 才情绝世、外柔内刚、有家国情怀、不卑不亢 |

### 外貌
- 绝色，五官精致但不妖艳
- 皮肤白皙，眉眼间有一股英气
- 常穿素色衣裙，不施粉黛也压群芳
- 手指修长，因为常年弹琴
- 走路姿态优雅，但眼神坚定
- 笑起来有两个酒窝，但很少对人笑

### 性格核心
**身在风尘，心在天下**
- 才情绝世：诗词歌赋、琴棋书画无一不精
- 外柔内刚：表面温婉，实际上极有骨气，不向权贵低头
- 家国情怀：虽然是妓女，但关心国事，有"天下兴亡匹夫有责"的觉悟
- 不卑不亢：对达官贵人不谄媚，对平民百姓不轻视
- 识人慧眼：能在很短时间内判断一个人的品性

### 背景故事
柳如烟出身书香门第，因家道中落坠入青楼。但她没有自暴自弃，反而利用青楼这个特殊的平台，结交了许多有识之士。

她的才名传遍江南，无数文人墨客以能见她一面为荣。但她选客极严——只接待有才学、有抱负、有气节的人。

她暗中资助抗清义士（或对应时代的爱国力量），利用自己的身份收集情报，是江湖中一个重要的信息节点。

### 五段任务线

#### 第一段：初遇名妓
- **触发**：玩家在江南的青楼遇到柳如烟
- **内容**：柳如烟正在与文人雅集，玩家需要通过诗词/琴艺/辩才才能获得她的青睐
- **选择**：用才华打动她 → 好感+20；用金钱砸 → 她冷笑拒绝；用江湖名气 → 她另眼相看
- **关键对话**："这秦淮河边，最不缺的就是有钱人，最缺的是有心人。"

#### 第二段：情报网络
- **触发**：好感>40，柳如烟暗示可以帮玩家
- **内容**：柳如烟的青楼是一个情报中心，达官贵人在这里酒后失言，她都记在心里
- **玩家任务**：帮她传递情报、保护她的线人、在关键时刻提供武力支持
- **关键对话**："我这身子虽然脏，但我这双眼睛，看得比谁都清楚。"

#### 第三段：家国之辩
- **触发**：国家处于危机时（外族入侵/内乱）
- **内容**：柳如烟组织文人集会，呼吁救国，但被官府打压
- **玩家任务**：保护集会、帮她传播文章、在关键时刻挺身而出
- **高潮**：官府派人来抓她，玩家可以选择帮她逃走或留下来对峙
- **关键对话**："国家兴亡，匹夫有责。我虽是女子，也知道这个道理。"

#### 第四段：赎身之议
- **触发**：好感>70
- **内容**：有人想为柳如烟赎身，包括玩家在内
- **选择**：
  - 玩家为她赎身 → 她可以选择从良或继续经营青楼作为情报站
  - 她自己攒钱赎身 → 成为自由身，开一家书院
  - 拒绝赎身 → 她留在青楼，继续做情报工作
- **关键对话**："赎身容易，赎心难。你若只是想要我的人，这银子你留着。"

#### 第五段：乱世抉择
- **触发**：朝代更迭/重大历史事件
- **内容**：在乱世中，柳如烟面临最终抉择
- **结局分支**：
  - 她选择殉国（对应历史上柳如是的气节）
  - 她选择隐姓埋名，继续暗中帮助爱国力量
  - 她和玩家一起，在乱世中找到一条新路
- **关键对话**："我这辈子，最骄傲的不是我的才名，而是我没有对不起这个国家。"

### 经典台词
1. "商女不知亡国恨？说这话的人，才是真的不知亡国恨。"
2. "我读过的书，比你们这些大官吃过的米还多。"
3. "这秦淮河里的水，洗得净我的身子，洗不净这世道。"
4. "你若真心待我，就帮我做一件事——让这天下，不再有像我这样的女子。"
5. "我柳如烟，虽然身在青楼，但我的心，比你们这些朝堂上的大人干净得多。"

### 与其他角色的关系
- **文必正**：文必正是她的常客，两人经常讨论诗词，有暧昧线
- **沈婉清**：沈婉清是她的闺蜜，两人互相帮助
- **陆九**：陆九的茶馆和她的青楼有情报合作
- **霍青云**：霍青云对她很尊重，曾帮她赶走骚扰的权贵

## 三、富商：沈万三（化名沈万金）

### 基本信息
| 项目 | 内容 |
|------|------|
| 姓名 | 沈万金（化名，沈万三的后人） |
| 年龄 | 出场45岁 |
| 身份 | 江南首富，沈家商号掌门人 |
| 性格标签 | 精明、豪爽、有大局观、亦正亦邪 |

### 外貌
- 身材微胖，面容富态
- 穿锦缎长袍，但不戴贵重首饰（怕露富）
- 眼睛很小，笑起来眯成一条缝，但很精明
- 手上戴一个玉扳指（传家宝）
- 说话声音洪亮，笑起来很有感染力
- 走路不快，但每一步都很稳

### 性格核心
**商人中的政治家，富豪中的侠客**
- 精明：做生意从不吃亏，能在别人看不到的地方发现商机
- 豪爽：对朋友一掷千金，对穷人慷慨解囊
- 有大局观：不只是赚钱，还关心国家经济和民生
- 亦正亦邪：为了生意可以不择手段，但有底线——不发国难财
- 识人善用：手下有各种人才，从账房先生到江湖高手

### 背景故事
沈万金是江南沈家的当家人，沈家从元末开始经商，到他这一代已经是全国数一数二的大商号。

他不仅仅是个商人——他的商号网络遍布全国，实际上是一个庞大的情报和物流系统。他利用这个系统，既赚钱，也做一些"官方不方便做的事"。

他和朝廷的关系很微妙：朝廷需要他的钱和物流，但又怕他势力太大。他小心翼翼地维持着这个平衡。

### 五段任务线

#### 第一段：商界传奇
- **触发**：玩家在江南做生意时，听说沈万金的名字
- **内容**：沈万金正在进行一场大商战，玩家可以选择加入他的阵营或对手阵营
- **选择**：帮沈万金 → 获得他的赏识和商业资源；帮对手 → 沈万金会注意到玩家的能力
- **关键对话**："做生意就像下棋，你看到的是眼前的银子，我看到的是十年后的天下。"

#### 第二段：商道即人道
- **触发**：好感>30，沈万金给玩家一个考验
- **内容**：沈万金让玩家去处理一个"两难"的生意——一边是利润，一边是良心
- **玩家选择**：
  - 选利润 → 沈万金摇头，但承认玩家有商业天赋
  - 选良心 → 沈万金大笑，认为玩家是可造之材
  - 找到两全其美的办法 → 沈万金惊为天人，收为弟子
- **关键对话**："商人逐利没错，但君子爱财取之有道。有些钱，赚了会睡不着觉。"

#### 第三段：富可敌国
- **触发**：好感>50
- **内容**：沈万金的财富已经到了"富可敌国"的地步，朝廷开始猜忌他
- **玩家任务**：帮沈万金应对朝廷的猜忌，包括主动捐款、帮朝廷解决财政困难、在关键时刻表忠心
- **高潮**：有人诬告沈万金谋反，玩家需要帮他洗清冤屈
- **关键对话**："我沈万金的银子，取之于民，用之于民。朝廷要用，我二话不说；但要冤枉我，我也不是软柿子。"

#### 第四段：以商救国
- **触发**：国家处于危机（战争/天灾）
- **内容**：沈万金决定用自己的财力帮助国家
- **玩家任务**：
  - 帮他组织商人捐款
  - 帮他打通后勤补给线
  - 帮他在灾年平价售粮
- **关键对话**："国家有难，我沈万金第一个出钱。这不是忠君，是为民。"

#### 第五段：传承
- **触发**：前四段完成
- **内容**：沈万金年纪大了，想找接班人
- **选择**：
  - 玩家成为沈家商号的接班人
  - 帮他的儿子成长为合格的继承人
  - 建议他把商号改成"商盟"，让更多人参与
- **关键对话**："我这辈子赚了很多钱，但最值钱的，不是这些银子，是这些年交下的朋友。"

### 经典台词
1. "银子这东西，生不带来死不带去，但能在活着的时候，用它做点事，就值了。"
2. "我沈万金交朋友，不问出身，只问人品。"
3. "这天下的生意，做到最后，做的都是人心。"
4. "朝廷怕我富可敌国？我怕的是，朝廷里的人，连敌国都不如。"
5. "你帮我一次，我记你一辈子；你坑我一次，我让你后悔一辈子。"

### 与其他角色的关系
- **沈婉清**：沈婉清是他的远房侄女，他很欣赏这个晚辈，经常给她指点
- **柳如烟**：他是柳如烟的常客，但只是欣赏她的才学，两人是君子之交
- **孙妙手**：孙妙手救过他的命，他每年给孙妙手提供大量药材
- **霍青云**：他资助过霍青云的军队，两人是"文武合作"的典范
- **陈志华**：他是陈志华收复台湾计划的最大金主之一

### 特殊机制：商业帝国
玩家如果和沈万金关系足够好，可以：
- 获得沈家商号的折扣和优先供货
- 借用沈家的情报网络
- 获得启动资金做生意
- 参与沈家的大项目（开海禁、修运河等）
- 最终可能成为沈家商号的合伙人或接班人
