# 山河纪元 · 音乐与音效系统设计文档

> 音乐不是背景。音乐是历史的呼吸。
> 当玩家站在城楼上看着大一统王朝建立时，配乐要让他起鸡皮疙瘩。

---

## 一、设计理念

### 核心原则
1. **自适应音乐（Adaptive Music）**：音乐随玩家所处情境实时变化，不是固定曲目循环
2. **地域辨识度**：不同区域有不同的乐器和旋律风格，玩家一听就知道到了哪里
3. **情绪驱动**：音乐服务于情感体验，关键历史时刻要有专属配乐
4. **文化气韵**：管弦乐+民族乐器融合，参考《全面战争：三国》但更有中国气韵

### 参考作品
- 《全面战争：三国》—— 战争与战略配乐
- 《对马岛之魂》—— 民族乐器与氛围音乐
- 《太吾绘卷》—— 中式人生模拟的音乐调性
- 《十字军之王3》—— 自适应分层音乐

## 二、三层自适应音乐架构

```
┌─────────────────────────────────────────────┐
│           第三层：历史性时刻触发层            │
│  (王朝建立/覆灭、大一统、重大战役、玩家成就)   │
│      专属配乐，强制覆盖，不可跳过             │
├─────────────────────────────────────────────┤
│           第二层：情绪驱动层                  │
│  (根据当前情境动态叠加/切换)                  │
│  太平/紧张/战争/史诗/悲壮/凯旋/节庆/怀古      │
├─────────────────────────────────────────────┤
│           第一层：地域氛围层（持续底噪）       │
│  (江南丝竹/北方鼓点/西域胡乐/沿海渔歌/中原雅乐) │
│  随玩家所在区域无缝切换                       │
└─────────────────────────────────────────────┘
```

### 第一层：地域氛围层（持续播放）

| 区域 | 主导乐器 | 音乐风格 | 节奏 | 参考 |
|------|---------|---------|------|------|
| 江南水乡 | 笛子、古筝、琵琶 | 丝竹雅乐，婉转悠扬 | 慢/中 | 《春江花月夜》 |
| 北方平原 | 鼓、唢呐、二胡 | 粗犷豪迈，节奏有力 | 中/快 | 陕北民歌、鼓乐 |
| 西北边疆 | 胡琴、琵琶、手鼓 | 西域风情，苍凉辽阔 | 中 | 丝路音乐 |
| 西南山区 | 芦笙、笛、鼓 | 少数民族风情，神秘 | 慢/中 | 云贵民乐 |
| 东南沿海 | 渔鼓、笛、海螺 | 渔歌号子，开阔 | 中 | 闽南/潮汕音乐 |
| 中原腹地 | 编钟、古琴、瑟 | 宫廷雅乐，庄重 | 慢 | 先秦雅乐 |
| 东南海岛(台湾) | 笛、月琴、鼓 | 闽南+原住民融合，亲切 | 中 | 台湾民谣 |

**实现方式**：每个区域有一个持续的氛围音轨（Ambient Loop），玩家进入新区域时通过MetaSounds的Crossfade参数在3-5秒内无缝过渡。

### 第二层：情绪驱动层（动态叠加）

8种情绪状态，每种对应一个音乐Stem（音轨分轨），可独立淡入淡出：

| 情绪 | 触发条件 | 乐器配置 | 调性 | BPM |
|------|---------|---------|------|-----|
| **太平** | 和平时期、村庄日常 | 古筝+笛子+轻弦乐 | 大调 | 60-80 |
| **紧张** | 即将开战、朝堂斗争 | 低音弦乐+定音鼓+不协和音 | 小调 | 90-110 |
| **战争** | 战斗进行中 | 全管弦+大鼓+铜管+呐喊 | 小调/减音阶 | 120-140 |
| **史诗** | 大战关键时刻、大军压境 | 全管弦+合唱+铜管独奏 | 大调/史诗进行 | 100-120 |
| **悲壮** | 战败、牺牲、城破 | 大提琴+二胡+低沉合唱 | 小调/慢板 | 50-70 |
| **凯旋** | 战争胜利、大一统 | 铜管+大鼓+欢快弦乐 | 大调 | 100-120 |
| **节庆** | 春节/中秋/端午等节日 | 唢呐+锣鼓+欢快丝竹 | 大调 | 100-130 |
| **怀古** | 历史遗迹、回忆、CG过场 | 古琴+箫+空灵合唱 | 五声音阶 | 40-60 |

**实现方式**：使用MetaSounds的Parameter接口，由C++的`AudioManager`根据游戏状态设置`MoodParameter`（0-7），MetaSounds内部根据参数交叉淡入对应Stem。

以下时刻触发专属CG配乐，强制覆盖前两层，播放期间不可跳过（可设置首次不可跳过，之后可跳过）：

### 模块化拼接素材（降低成本）

除了15首核心曲目，其余日常音乐用**模块化素材拼接**：
- 10个旋律片段（笛子/古筝/二胡/琵琶各2-3个）
- 8个节奏型（鼓点/低音）
- 6个和声进行（大调/小调/五声等）
- 4个情绪过渡片段（用于情绪切换时的过渡）

MetaSounds根据当前区域和情绪，实时组合这些素材，产生无穷变化。

## 四、MetaSounds实现方案

### 音频文件组织
```
Content/Audio/
├── Music/
│   ├── Core/                    # 15首核心曲目
│   │   ├── M_MainTheme.uasset
│   │   ├── M_Founding.uasset
│   │   └── ...
│   ├── Regional/                # 地域氛围层
│   │   ├── Ambient_Jiangnan.uasset
│   │   ├── Ambient_North.uasset
│   │   └── ...
│   ├── MoodStems/               # 情绪层分轨
│   │   ├── Stem_Peaceful.uasset
│   │   ├── Stem_War.uasset
│   │   └── ...
│   └── Modules/                 # 模块化素材
│       ├── Melodies/
│       ├── Rhythms/
│       └── Harmonies/
├── SFX/                         # 音效
│   ├── Combat/
│   ├── Ambient/
│   ├── UI/
│   └── Voice/
└── MetaSounds/
    ├── MS_AdaptiveMusic.uasset  # 主自适应音乐MetaSound
    └── MS_RegionalAmbient.uasset
```

### MetaSounds参数接口

```
Parameters (输入):
  - RegionIndex (int, 0-6)      : 当前区域索引
  - MoodIndex (int, 0-7)        : 当前情绪索引
  - Intensity (float, 0-1)      : 情绪强度（战争越激烈值越高）
  - CGTrigger (int, -1=无)      : CG触发索引，-1表示正常播放
  - MasterVolume (float, 0-1)
  - MusicVolume (float, 0-1)

内部逻辑:
  1. 根据RegionIndex选择地域氛围层，Crossfade切换
  2. 根据MoodIndex+Intensity淡入对应情绪Stem
  3. 如果CGTrigger != -1，强制切换到CG曲目
  4. 所有音量受MasterVolume*MusicVolume控制
```

### C++侧调用（已在AudioManager中实现）

```cpp
// 设置情绪 - 自动切换音乐
AudioManager->SetMusicMood(EMusicMood::War);

// 播放CG配乐
AudioManager->PlayCGMusic(TEXT("Founding"));

// 动态调整战争强度
AudioManager->SetWarIntensity(0.8f);
```

## 五、音效设计

### 环境音效
- **乡村**：鸡鸣、犬吠、鸟鸣、风声、溪水、农具声
- **城市**：叫卖声、车马声、孩童嬉闹、酒馆喧闹、寺庙钟声
- **朝堂**：脚步声、衣袍摩擦、竹简翻动、远处更鼓
- **战场**：兵器碰撞、呐喊、马蹄、鼓声、号角、箭矢破空
- **边疆**：风沙、驼铃、胡笳、远处狼嚎

### UI音效
- 按钮点击：木质敲击声（国风）
- 弹窗：竹简展开声
- 确认：玉佩碰撞声
- 错误：低沉锣声

### 语音
- 中文：全配音（关键剧情+日常对话）
- 英文/日文：关键剧情+CG配音，日常对话文字+音效

## 六、技术规格

| 项目 | 规格 |
|------|------|
| 格式 | WAV（源文件）、OGG（引擎内压缩） |
| 采样率 | 44100 Hz |
| 位深 | 16-bit |
| 声道 | 立体声（音乐）、单声道（音效） |
| 音乐总时长 | 核心45分钟 + 模块化无限拼接 |
| 音效数量 | 约300个 |
| 内存占用 | 音乐流式加载，常驻内存<50MB |
