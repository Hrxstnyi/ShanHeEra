# 角色人设 · 陆九（茶馆老板）

> "客官，喝茶。这茶啊，要慢慢品。急了，就苦了。"
> "（擦着杯子，头也不抬）你说的那件事，我什么都没听见。"

---

## 一、基础信息

| 项目 | 内容 |
|------|------|
| **姓名** | 陆九（没人知道他的真名，因为他是家里老九） |
| **绰号** | 九爷、茶馆里的活神仙 |
| **年龄** | 看起来五十多，实际年龄是谜（有人说七十，有人说九十） |
| **性别** | 男 |
| **身份** | 县城"忘忧茶馆"老板 / 信息枢纽 / 隐藏剧情触发者 |
| **社会阶层** | 平民（实际影响力远超表面） |
| **所在地** | 中原腹地·开封府 |
| **配音方向** | 中年男性，声音低沉温和，语速慢，永远像在说一件无关紧要的事，但每个字都有分量 |

---

## 二、外貌描写

### 整体形象
身高一米七左右，微胖，永远穿着一件干净的灰色布袍，袖口卷到手肘。走路很慢，像在散步，但从不会被任何东西绊倒。他的存在感很低，你经常会忽略他的存在，但他总是在那里。

### 面部
- 圆脸，总是笑眯眯的，眼睛眯成一条缝，看起来像个弥勒佛
- 但仔细看，他的眼睛里没有笑意，深不见底
- 右手缺了小指（从根部断的，旧伤，他从不提）
- 脸上有一道很浅的疤，从右耳到下巴，被胡子遮住了大半
- 胡子修剪得很整齐，灰白相间

### 穿着
- 灰色布袍，永远干净得不像一个开茶馆的
- 腰间系着一条黑色围裙，上面没有茶渍（"干这行的，围裙脏了就不专业了"）
- 脚上是一双布鞋，鞋底很薄，走路没声音
- 左手手腕上戴着一个旧的铜镯子（来历是谜）

### 标志性物品
- **茶壶**：一把用了几十年的紫砂壶，壶身锃亮，他泡茶的动作像在表演
- **抹布**：永远在擦杯子，擦杯子时是他最放松的时候，也是他最危险的时候
- **铜镯子**：左手的旧铜镯，上面刻着看不懂的符号

---

## 三、性格特质

### 核心性格：大智若愚 + 信息掌控者

| 表面 | 内里 |
|------|------|
| 和气生财，对谁都笑眯眯的 | 把所有人的秘密都记在心里 |
| 什么都不知道，什么都不掺和 | 什么都知道，什么都在他的掌控中 |
| 胆小怕事，从不惹麻烦 | 麻烦都是他制造的，只是没人知道 |
| 一个普通的茶馆老板 | 可能是前朝余孽、可能是锦衣卫、可能是江湖老大——总之不简单 |
| 说话模棱两可，从不给明确答案 | 他说的每一句话都是答案，只是你听不懂 |

### 性格细节

**和气的一面：**
- 对乞丐也客客气气，会给一碗免费的茶
- 从不与人争执，别人吵架他就添茶
- 记得每个常客的口味，不用问就知道你要什么茶
- 谁家有困难，他会"恰好"路过，留下点东西就走

**深不可测的一面：**
- 你刚决定要做一件事，他已经知道了
- 官府要抓的人，经常"恰好"在他茶馆里躲过追捕
- 江湖上的大事，他总是第一个知道，但从不主动说
- 有人问他的过去，他就开始擦杯子，擦到你不好意思再问

### 口头禅
- "喝茶，喝茶。"（不想回答时）
- "这事儿啊，不好说。"（其实他知道答案）
- "你听说了吗？……算了，没什么。"（故意吊胃口）
- "慢走，下次再来。"（可能是告别，也可能是警告）
- （认真时）"有些事，知道得越少，活得越久。"

## 四、背景故事

### 没人知道的过去
陆九的过去是整个游戏最大的谜团之一。不同的NPC会给出不同的说法：
- 有人说他是前朝的锦衣卫指挥使，王朝更迭后隐姓埋名
- 有人说他是江湖上最大的情报组织"听雨楼"的楼主
- 有人说他是当年的状元郎，因为得罪了权贵被灭门，只有他逃了出来
- 还有人说他就是个普通的茶馆老板，那些传说都是他自己编的

他对所有说法都不承认也不否认，只是笑。

### 已知的事实
- 他在开封开茶馆开了三十年
- 三十年前，开封发生过一场大案，很多人失踪了，他的茶馆就是那年开的
- 他认识三教九流的人，从乞丐到官员都跟他有交情
- 他的右手小指是三十年前断的，跟那场大案有关

### 隐藏线
玩家可以通过一系列任务慢慢揭开他的过去。最终发现：他确实是前朝的情报人员，王朝更迭后他选择了隐退，开了个茶馆。但他没有真正退出，而是用茶馆做掩护，建立了一个民间情报网，用来保护那些被官府迫害的人。

他的右手小指，是当年为了救一个孩子，自己砍断的（那个孩子就是后来的某个重要角色）。

## 五、技能与能力

### 已知技能
| 技能 | 等级 | 说明 |
|------|------|------|
| 泡茶 | 100/100 | 游戏里最好的茶，喝了能恢复体力、增加灵感 |
| 情报 | ??? | 没人知道他的情报网有多大 |
| 武功 | ??? | 从没见过他动手，但想在他茶馆闹事的人都"恰好"摔倒了 |
| 识人 | 100/100 | 看你一眼就知道你是什么人、来干什么 |
| 医术 | 80/100 | 他的茶能"治病"，其实是加了草药 |

### 能给玩家的
- 信息（但要换，他不会白给）
- 任务（隐藏剧情线的入口）
- 庇护（被官府追杀时可以躲在他茶馆）
- 人生建议（他说的话都有深意，需要玩家自己领悟）

## 六、对话风格示例

### 日常（打哑谜模式）

> **玩家**：九爷，您知道最近城里有什么新鲜事吗？
>
> **陆九**：（擦着杯子）新鲜事啊……昨天王屠夫家的猪跑了，今天自己回来了。你说，这猪是不是通人性？
>
> **玩家**：……我问的不是这个。
>
> **陆九**：（笑）那你问的是哪个？这城里每天都有新鲜事，看你想听哪个了。（倒茶）喝茶，这茶刚泡的。

> **玩家**：九爷，您到底是什么人？
>
> **陆九**：（停下擦杯子的动作，看了玩家一眼，然后继续擦）我？一个开茶馆的。你看这杯子，要擦得干净，就得慢慢来。急了，就碎了。（顿了顿）人也一样。

### 关键时刻（暗示模式）

> **场景**：玩家被官府通缉，走投无路，跑到茶馆。
>
> **陆九**：（看了一眼，什么都没说，指了指后厨）后面有个地窖，先躲躲。
>
> **玩家**：九爷，您不怕被牵连？
>
> **陆九**：（笑）我这茶馆，三十年来什么人没来过？官府的人也来喝茶。他们喝茶的时候，不会看后厨。（顿了顿）不过你记住，躲得了一时，躲不了一世。该面对的，总要面对。

> **场景**：玩家在做一个重大决定前，来茶馆喝茶。
>
> **陆九**：（倒茶）你这杯茶，喝了二十年了吧？
>
> **玩家**：……我才认识您几年。
>
> **陆九**：（笑）我说的是这杯茶的味道。你现在喝，和十年后喝，味道不一样。不是茶变了，是你变了。（看着玩家）想好了再做决定。有些路，走了就回不了头。

### 隐藏剧情（真相时刻）

> **场景**：玩家终于查到了陆九的过去， confronting him。
>
> **玩家**：九爷，三十年前那场大案，是您做的吧？
>
> **陆九**：（很久没有说话，手里的杯子放下了。这是玩家第一次看到他不擦杯子）
>
> **陆九**：（声音很轻）你查到了多少？
>
> **玩家**： enough。
>
> **陆九**：（叹了口气，第一次收起了笑容）坐吧。有些事，憋了三十年，也该有人知道了。（卷起右手袖子，露出断指）这根手指，是我自己砍的。为了救一个孩子。那个孩子，现在应该……也不小了。

## 七、个人任务线

### 任务一：《茶馆里的陌生人》
- 玩家第一次来茶馆，陆九"恰好"知道玩家需要什么信息
- 但他不白给，要求玩家帮他做一件小事（送一封信）
- 送信过程中触发第一个隐藏剧情

### 任务二：《听雨楼》
- 玩家发现陆九和一个叫"听雨楼"的神秘组织有关
- 陆九不承认也不否认，给了玩家更多线索
- 玩家可以选择加入听雨楼，或继续调查

### 任务三：《三十年前》
- 玩家查到三十年前的大案线索
- 陆九的过去逐渐揭开
- 玩家发现陆九这些年一直在保护当年大案的幸存者

### 任务四：《最后一杯茶》
- 当年的仇家找到了陆九
- 玩家可以选择帮陆九，或让他自己面对
- 最终战中，陆九第一次（也是唯一一次）展示了真正的武功
- 战后，他回到茶馆，继续擦杯子，"都过去了。喝茶。"

---

## 八、角色弧光

```
始终：神秘 → 若隐若现 → 玩家自己拼凑真相
  ↓
（没有传统的"成长"，他是已经完成的人）
  ↓
终章：他选择继续做一个茶馆老板，因为这是他想要的生活
```

**核心主题**：陆九是一个"已经完成了人生"的角色。他的故事不是成长，而是被发现。他代表的是那些在历史中默默做事、不求名利的人——你不知道他们的名字，但他们一直在那里。
