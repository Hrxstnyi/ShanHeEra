## 一、项目概述

**山河纪元·华夏古代人生模拟器**是一款融合《骑马与砍杀》战场战术、《十字军之王3》大地图战略、《太吾绘卷》个人人生模拟的动态沙盘RPG/历史模拟器。

**核心立意**：玩家不是天命之人，只是时代中的一个生命。世界不围绕玩家运行，AI NPC 自主决策，历史在玩家介入或旁观中自然演进。

### 2.2 模块划分
```
Source/ShanHeEra/
├── Core/          # 核心系统（游戏模式、存档、性能、调试、数据配置）
├── World/         # 世界模拟（城市、区域、建筑、昼夜、天气、导航、旅行事件）
├── Character/     # 角色系统（玩家、NPC、NPC片段、属性）
├── Dynasty/       # 王朝系统（朝廷、科举、宫廷斗争）
├── Economy/       # 经济系统（贸易、物价、平衡）
├── Military/      # 军事系统（战争、战斗、兵种）
├── Family/        # 家族系统（族谱、传承、婚姻）
├── Society/       # 社会系统（江湖、武功、社交）
├── History/       # 历史系统（事件、天灾、剧本）
├── Culture/       # 文化系统（科技、文学、医学、宗教、烹饪、节日）
├── Audio/         # 音频系统（音乐、音效、CG、空间音频）
├── Story/         # 剧情系统（任务、故事、对话）
└── UI/            # 用户界面（12个界面+基类）
```

## 十一、已知限制

1. **资产占位**：代码中引用的资产路径（音频、特效、CG）为字符串占位，需在UE编辑器中导入实际资产
2. **蓝图缺失**：需要创建GameMode、PlayerController、HUD等蓝图类并绑定C++类
3. **地图缺失**：需要创建基础关卡地图
4. **UI蓝图**：UMG界面需要在编辑器中创建并绑定C++基类
5. **输入配置**：Enhanced Input的InputAction和MappingContext需要创建
