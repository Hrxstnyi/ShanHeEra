# 霍青云 — 少年将军 完整人设

## 基本信息

| 项目 | 内容 |
|------|------|
| 姓名 | 霍青云 |
| 字 | 子腾 |
| 年龄 | 出场16岁，主线最高28岁 |
| 身份 | 边军小将 → 偏将 → 大将军 |
| 出身 | 军户世家，父亲战死沙场 |
| 阵营 | 朝廷（鹰派） |
| 武器 | 长枪「破阵」，家传 |

## 外貌描写

- 身高八尺，肩宽腰窄，常年日晒的古铜色皮肤
- 剑眉星目，鼻梁高挺，嘴角总带着一丝不服输的傲气
- 左眉骨有一道浅疤，是14岁第一次上战场留下的
- 穿银甲时英气逼人，卸甲后只着粗布短打，像个农家少年
- 走路带风，说话声如洪钟，笑起来露出一口白牙

## 性格核心

**少年意气 + 赤子之心 + 军事天才**

- **傲气但不傲慢**：对自己的武艺和兵法极度自信，但尊重真正有本事的人
- **直率**：心里想什么说什么，不会拐弯抹角，朝堂上经常得罪人
- **护短**：对自己的兵像兄弟，谁动他的兵他跟谁拼命
- **天真的理想主义**：真心相信"武将守土有责"，不懂政治倾轧
- **成长弧光**：从"我要当天下第一武将"的少年，到理解"战争的意义是保护百姓"的将军

## 背景故事

霍青云出身西北边军世家，祖上三代都是守边的武将。父亲霍震是边关副将，在他12岁那年死于匈奴突袭。

14岁，他以军户子弟身份入伍，因为年纪小被分配到辎重营。但他不甘心，在一次敌军偷袭中，他单人匹马冲阵，一枪挑落敌军百夫长，一战成名，被破格提拔为什长。

16岁，已经是百夫长，统领百人。在一次守城战中，他以少胜多，击退三倍于己的敌军，被调入京营，成为最年轻的校尉。

## 五段任务线

### 第一段：初出茅庐（16岁）
- **触发**：玩家在京城遇到正在与人争执的霍青云
- **内容**：霍青云因为顶撞上司被责罚，玩家可以选择帮他说话或冷眼旁观
- **选择影响**：帮他 → 好感+30，开启后续线；旁观 → 他被调往边疆，很久才能再遇到
- **关键对话**："我霍青云打仗从不后退，凭什么要给那些只会动嘴皮子的人让路？"

### 第二段：边关历练（18-20岁）
- **触发**：好感>50，霍青云邀请玩家去边关
- **内容**：跟随霍青云驻守边关，经历三次大小战斗，体验骑砍式战斗
- **高潮**：敌军大军压境，主将畏战，霍青云擅自出战，以少胜多但违反军令
- **选择**：帮他在朝堂上辩护 → 他升偏将；不帮 → 他被贬但仍守边关
- **关键对话**："将在外，君命有所不受。等那些文官商量完，边关早就破了！"

### 第三段：京城风云（22岁）
- **触发**：霍青云回京述职，卷入朝堂党争
- **内容**：文官集团想拉拢他，武将集团想排挤他，他两头不讨好
- **高潮**：有人诬告他通敌，玩家需要帮他洗清冤屈
- **选择**：找到证据为他平反 → 他升将军；失败 → 他下狱，需要劫狱（江湖线）
- **关键对话**："我霍青云对得起天地良心，通敌？我爹就是死在匈奴手里的！"

### 第四段：大战封神（25岁）
- **触发**：外敌大举入侵，朝廷无人可用
- **内容**：霍青云被重新启用，统领大军，玩家可以选择加入他的军队
- **高潮**：决定性战役，玩家可以亲自参与指挥（骑砍式大战场）
- **结局分支**：
  - 大胜 → 霍青云封大将军，"少年将军"名扬天下，触发爱国彩蛋
  - 惨胜 → 霍青云重伤，但守住了国土
  - 战败 → 霍青云战死，玩家继承他的遗志

### 第五段：功成身退（28岁）
- **触发**：第四段大胜后
- **内容**：天下太平，霍青云面临"功高震主"的困境
- **选择**：
  - 劝他急流勇退 → 他回乡教书，善终
  - 支持他继续掌兵 → 可能被猜忌，也可能成为护国柱石
  - 劝他造反 → 他暴怒，与玩家决裂（除非玩家走谋反线）
- **关键对话**："我学武是为了保家卫国，不是为了黄袍加身。天下太平了，我也该歇歇了。"

## 角色弧光

```
16岁：傲气少年，只想证明自己
    ↓ 经历战争的残酷
20岁：开始理解士兵的生命重量
    ↓ 经历朝堂的黑暗
23岁：怀疑自己坚持的意义
    ↓ 大战中找到答案
25岁：明白"战争是为了不再有战争"
    ↓
28岁：从容放下，守护得来不易的和平
```

## 与其他角色的关系

- **苏忘机**：霍青云小时候的邻居，苏忘机教过他修兵器，两人亦师亦友
- **赵红缨**：不打不相识，后来成为战场上的搭档（有暧昧线）
- **文必正**：一文一武，经常吵架但关键时刻互相支持
- **陆九**：霍青云怀疑陆九的身份，但查不出什么
- **陈志华**：霍青云支持收复台湾，是陈志华在朝中的最大助力

## 玩家互动

- 可以拜他为师学枪法（战斗技能线）
- 可以加入他的军队走武将路线
- 可以帮他处理朝堂关系（官场路线）
- 他是爱国彩蛋"精忠报国"的关键触发角色
