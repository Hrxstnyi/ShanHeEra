## BGM-01：山河序

**类型**：主题音乐（Main Theme）
**时长**：3:00
**调性**：D大调转d小调
**速度**：♩=72（慢板）
**配器**：
- 弦乐组（小提琴I/II、中提琴、大提琴、低音提琴）
- 铜管组（圆号4支、小号2支、长号2支、大号）
- 木管组（长笛2支、双簧管2支、单簧管2支、大管2支）
- 打击乐（定音鼓、大鼓、钹、编钟、古筝）
- 独奏乐器（二胡、竹笛）

**旋律设计**：
- 0:00-0:30 引子：编钟轻敲，古筝泛音，营造悠远的历史感
- 0:30-1:00 呈示部：圆号奏出主主题，庄严恢弘，弦乐铺垫
- 1:00-1:30 发展部：二胡独奏主题变奏，转为小调，表现历史的沧桑
- 1:30-2:15 再现部：全乐队合奏主题，铜管辉煌，达到高潮
- 2:15-2:45 尾声：竹笛独奏，逐渐减弱，余韵悠长
- 2:45-3:00 结束：编钟最后一响，归于寂静

**情绪曲线**：庄严(0:00) → 恢弘(0:30) → 沧桑(1:00) → 辉煌(1:30) → 悠远(2:15) → 寂静(2:45)

**使用场景**：游戏启动主菜单、新游戏开场CG、制作人员名单

## BGM-02：市井烟火

**类型**：环境音乐（城市日常）
**时长**：4:00（可循环）
**调性**：G大调
**速度**：♩=100（中板）
**配器**：
- 弹拨乐（琵琶、扬琴、中阮）
- 吹管乐（笛子、唢呐（低音区）、笙）
- 打击乐（板鼓、小锣、木鱼）
- 低音（大提琴、低音提琴）

**旋律设计**：
- 轻快的琵琶轮指开场，模拟集市的喧闹
- 笛子奏出活泼的旋律，表现市井的生机
- 中段加入唢呐（低音区，不刺耳），表现商贩的吆喝
- 扬琴点缀，像铜钱碰撞的声音
- 整体循环流畅，没有明显的起止点

**情绪**：热闹、温馨、充满生活气息

**使用场景**：城市街道、集市、白天的居民区

## BGM-07：血战到底

**类型**：战斗音乐（决定性战役/Boss战）
**时长**：4:00
**调性**：f小调转F大调
**速度**：♩=160（急板）→ ♩=80（广板）
**配器**：
- 全管弦乐队
- 额外打击乐（军鼓、钹、锣、编钟）
- 合唱（男声合唱，无歌词的"啊"音）
- 独奏乐器（二胡（悲壮段）、琵琶（武曲段））

**旋律设计**：
- 0:00-0:30 序奏：低沉的大鼓，弦乐颤音，山雨欲来
- 0:30-1:30 激战：全乐队急速演奏，铜管咆哮，弦乐飞奔
- 1:30-2:00 转折：音乐骤停，只剩二胡独奏，悲壮苍凉
- 2:00-3:00 决战：合唱加入，全乐队最强奏，达到整个曲目的高潮
- 3:00-3:30 尾声：音乐逐渐减弱，转为大调，表现胜利或悲壮的结局
- 3:30-4:00 结束：最后一个长音，余韵消散

**情绪曲线**：紧张(0:00) → 激烈(0:30) → 悲壮(1:30) → 史诗(2:00) → 释然(3:00) → 余韵(3:30)

**使用场景**：决定性战役、Boss战、CG-03大战开幕、CG-05精忠报国

## BGM-15：王朝终章

**类型**：事件音乐（王朝建立/覆灭）
**时长**：4:00

- 管风琴（建立段高潮）

**旋律设计**：
- 0:00-1:00 覆灭段：二胡独奏，低沉悲凉，弦乐低音持续，表现王朝的衰亡
- 1:00-1:40 转折：音乐逐渐变化，定音鼓敲响，暗示新的力量崛起

## 音乐系统技术说明

### 自适应音乐（Adaptive Music）
- 所有BGM都分为多个层次（Layer），可根据游戏状态动态叠加
- 例如：市井烟火 = 基础层（琵琶+笛子）+ 热闹层（唢呐+打击乐）+ 事件层（特殊音效）
- 玩家进入战斗时，环境音乐平滑过渡到战斗音乐（3-5秒交叉淡入淡出）

### 音乐与情绪联动
- 玩家的行为会影响音乐的情绪层
- 例如：在城市中犯罪 → 音乐加入紧张层；做好事 → 音乐加入温暖层

### 三语版本
- 有歌词的曲目（BGM-12精忠报国）录制中/英/日三个版本
- 中文：原词"精忠报国"
- 英文："Loyal to the Nation"
- 日文：「国に忠義を」

### 音质规格
- 格式：WAV（48kHz/24bit）母带，游戏内用OGG Vorbis（品质10）
- 总大小：约150MB（15首×平均10MB）
- 流式加载：长曲目（>2分钟）使用流式加载，不占用内存
