## 二、价格波动模型

### 核心公式
```
当前价格 = 基础价格 × (需求 / 供给) × 季节因子 × (1 + 通胀率)
```

### 供给需求模型
- **供给**：产量 - 消耗 + 库存
- **需求**：人口 × 人均消费 + 政府采购 + 商人囤积
- 供需比 > 1.2 → 价格下降30%
- 供需比 < 0.8 → 价格上涨50%
- 供需比 < 0.5 → 价格翻倍（短缺）

### 粮价季节波动
| 月份 | 季节因子 | 说明 |
|------|---------|------|
| 1-2月 | 1.2 | 冬季，存粮减少 |
| 3-4月 | 1.3 | 春荒，粮价最高 |
| 5-6月 | 1.0 | 初夏，正常 |
| 7-8月 | 0.9 | 夏收，粮价下降 |
| 9-10月 | 0.7 | 秋收，粮价最低 |
| 11-12月 | 0.9 | 初冬，开始回升 |

### 波动率设计
| 商品 | 波动率 | 原因 |
|------|--------|------|
| 粮食 | 30% | 受天气影响最大 |
| 盐 | 25% | 官营但有走私 |
| 药材 | 30% | 受产地和疫情影响 |
| 铁 | 15% | 军需，价格相对稳定 |
| 丝绸 | 10% | 奢侈品，需求稳定 |
| 书籍 | 5% | 文化品，价格稳定 |
| 瓷器 | 8% | 工艺稳定 |

## 三、通货膨胀模型

### 通胀原因
1. **货币超发**：朝廷铸钱过多 → 通胀+
2. **战争**：供给减少，军费增加 → 通胀+
3. **天灾**：粮食减产 → 粮价带动全面通胀
4. **盛世**：供给充足，贸易繁荣 → 通缩/稳定
5. **技术进步**：生产力提升 → 通缩压力

### 通胀影响
| 通胀率 | 效果 |
|--------|------|
| < -10% | 严重通缩，经济萧条，商人破产 |
| -5% ~ 0% | 温和通缩，物价下降 |
| 0% ~ 5% | 健康稳定 |
| 5% ~ 20% | 温和通胀，经济活跃 |
| 20% ~ 50% | 高通胀，百姓不满 |
| > 50% | 恶性通胀，货币信用崩溃，王朝危机 |

## 四、税收系统

### 税种与税率
| 税种 | 税率 | 说明 |
|------|------|------|
| 田税 | 5% ~ 15% | 按亩产征收，盛世低，乱世高 |
| 人头税 | 100铜钱/年 | 成人缴纳 |
| 商税 | 3% | 交易额 |
| 盐税 | 20% | 官营专卖 |
| 茶税 | 10% | 大宗商品 |
| 关税 | 5% | 边境/海关 |
| 徭役 | 20天/年 | 可交钱代役(每天20铜钱) |

### 税收平衡设计
- **税率 < 10%**：百姓满意，经济繁荣，但国库空虚
- **税率 10%-20%**：平衡，国库充足，百姓可承受
- **税率 20%-30%**：百姓不满，开始有怨言
- **税率 > 30%**：民怨沸腾，可能引发起义

### 王朝周期与税收
- **建立期**：低税率(5%)，休养生息
- **繁荣期**：中税率(10%)，国库充盈
- **衰落期**：高税率(20%)，财政困难
- **末期**：苛捐杂税(>30%)，官逼民反

## 五、贸易利润模型

### 利润公式
```
净利润 = (目的地价格 - 出发地价格) × 数量 - 运费 - 关税 - 损耗
```

### 利润区间
| 贸易类型 | 利润率 | 风险 |
|----------|--------|------|
| 短途粮食 | 5%-15% | 低 |
| 长途丝绸 | 20%-50% | 中 |
| 海盐走私 | 50%-100% | 高(违法) |
| 海外贸易 | 30%-80% | 高(风暴/海盗) |
| 军需物资 | 100%-200% | 极高(战争时期) |

### 贸易路线设计
| 路线 | 商品 | 基础利润 | 特殊事件 |
|------|------|---------|---------|
| 江南→京城 | 丝绸、茶叶、瓷器 | 30% | 漕运风险 |
| 北方→江南 | 皮毛、药材 | 25% | 盗匪风险 |
| 西北→中原 | 马匹、玉石 | 40% | 边关检查 |
| 福建→台湾 | 粮食、布匹 | 20% | 海禁风险 |
| 台湾→福建 | 糖、鹿皮 | 35% | 海峡风暴 |
| 广州→海外 | 丝绸、瓷器 | 60% | 海盗/风暴 |

## 七、玩家经济曲线

### 前期（0-5年）
- 目标：生存，积累第一桶金
- 收入来源：打工、务农、小买卖
- 月收入：500-2000铜钱
- 关键：不要破产，积累技能和人脉

### 中期（5-20年）
- 目标：建立稳定收入来源
- 收入来源：开店、作坊、商队、田产
- 月收入：5000-50000铜钱
- 关键：多元化经营，应对风险

### 后期（20年+）
- 目标：财富自由，影响区域经济
- 收入来源：商帮、钱庄、土地兼并、官商勾结
- 月收入：100两银+
- 关键：政治投资，家族传承

## 八、经济崩溃条件

游戏经济不会自然崩溃，但以下情况可能导致区域性经济危机：

1. **连续3年天灾** → 粮价>300% → 饥荒 → 流民 → 起义
2. **战争持续5年+** → 通胀>50% → 货币信用崩溃 → 以物易物
3. **税率>40%持续3年** → 商人破产 → 经济萧条 → 税收减少 → 恶性循环
4. **主要商路中断** → 物资短缺 → 价格飞涨 → 社会动荡

## 九、平衡校验清单

- [ ] 农民年收入 > 基本生存成本（避免开局即死）
- [ ] 商人利润率 < 100%（避免一夜暴富）
- [ ] 官员俸禄 > 商人中等收入（保证读书有价值）
- [ ] 粮价波动范围：150-5000铜钱/石（避免极端）
- [ ] 通胀率范围：-20% ~ +100%（避免数值爆炸）
- [ ] 税率上限50%（超过即王朝末期）
- [ ] 教育成本 < 10年农民收入（保证阶层流动可能）

---

*经济平衡的核心不是让数字好看，而是让玩家的每一个经济选择都有意义。*
