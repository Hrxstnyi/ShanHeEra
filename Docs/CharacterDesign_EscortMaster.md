# 角色人设 · 赵红缨（冷面女镖师）

> "镖在人在，镖亡人亡。这是规矩。"
> "……还有，下次再叫我'小姑娘'，我把你舌头割下来喂狗。"

---

| 项目 | 内容 |

| **姓名** | 赵红缨 |

| **年龄** | 26岁 |

## 二、外貌描写

### 整体形象
身高一米七，肩宽腰细，站姿笔直如枪。走路时步伐沉稳，每一步距离完全相同，那是长年走镖练出来的。身上永远带着一股淡淡的铁锈味和草药味。

### 面部
- 鹅蛋脸，眉目英气，左眼下方有一道浅疤（从眉骨到颧骨，据说是十五岁时劫镖留下的）
- 眼神锐利，看人时像在评估对方能不能接自己一刀
- 嘴唇薄，总是紧抿着，很少笑
- 左眉有一道断口（旧伤），让她看起来更凶

### 穿着
- 永远穿暗红色劲装，袖口扎紧，腰间系黑色宽腰带，别着一把短刀
- 外罩一件灰色披风，披风里子是暗红色的（行走江湖的低调，内里是她喜欢的颜色）
- 脚上是薄底快靴，靴筒里藏着一把匕首
- 头发用红色发带高高束成马尾，碎发用银簪固定
- 左手腕上戴着一串旧佛珠（她母亲的遗物，从不离身）

### 标志性物品
- **红缨枪**：一杆长枪，枪头下系着一簇红缨，是她的标志武器。枪杆上有密密麻麻的刀痕（挡刀留下的）
- **银质酒壶**：腰间挂着一个小酒壶，里面装的不是酒，是金疮药（"走镖的，随时可能受伤"）
- **佛珠**：左手腕的旧佛珠，紧张时会不自觉地拨动

## 三、性格特质

### 核心性格：外冷内热 + 极度靠谱

| 表面 | 内里 |
|------|------|
| 话少，表情少，看起来很凶 | 心软，见不得弱者被欺负 |
| 对谁都冷冰冰的 | 偷偷资助了三个孤儿（没人知道） |
| 说一不二，极其严格 | 对自己人护短到不讲理 |
| 不相信任何人 | 一旦信任就会豁出命去保护 |
| 看起来像个杀人不眨眼的魔头 | 连蚂蚁都舍不得踩（"它又没惹我"） |

### 性格细节

**冷的一面：**
- 说话不超过十个字，能一个字解决的绝不说两个
- 面无表情是常态，别人讲笑话她也不笑
- 对新手镖师极其严格，动作不对就一脚踹过去
- 谈价钱时寸步不让，"少一文都不走"

**热的一面：**
- 路过乞丐会默默放下几个铜板，然后快步走开，假装什么都没发生
- 手下镖师受伤，她会亲自上药，嘴上骂着"废物"，手却很轻
- 每年清明都会去一个孤儿的坟前烧纸（那个孤儿是她没保护好的）
- 看到小孩被欺负会出手，但打完人后会凶那个小孩"哭什么哭，没出息"

### 口头禅
- "规矩。"（解释一切行为的理由）
- "让开。"（不想废话时）
- "……哼。"（表示不屑，但其实可能是同意）
- （罕见温柔时）"没事了。"

## 四、背景故事

### 出身
赵红缨出身于镖师世家，父亲赵镇远是镇远镖局的总镖头，江湖上赫赫有名的"铁臂螳螂"。她是独女，从小被当男孩养，五岁开始练武，七岁跟着走镖。

### 转折：十五岁那年
十五岁时，她第一次独立押镖，走的是洛阳到长安的线。途中遇到劫匪，她拼死保护镖银，但同行的一个老镖师为了掩护她战死了。那个老镖师叫周伯，是看着她长大的，临死前对她说"红缨，别哭，走镖的人，不能哭"。

从那以后，她再也没哭过。性格也从一个活泼的少女变成了现在这个冷冰冰的样子。

### 现在
父亲年老体衰，她二十岁接手镖局，六年时间把镇远镖局从洛阳一地做到了覆盖北方五省的大镖局。江湖上提到"红罗刹"，没有不给面子的。

但她心里一直有个结：当年劫镖的人，她查了十年还没查到主谋。这条线会在后续剧情中展开。

### 隐藏身份
- 她偷偷资助的三个孤儿，其中一个是当年战死的周伯的孙子
- 她的佛珠是母亲的遗物，母亲在她十岁时病逝，她一直觉得是自己练武太忙没陪母亲
- 她其实很喜欢绣花，但觉得"练刀的手绣花太丢人"，只在深夜没人时绣

## 五、技能与能力

### 武艺
| 技能 | 等级 | 说明 |
|------|------|------|
| 枪法 | 92/100 | 家传"燎原枪法"，大开大合，战场杀器 |
| 刀法 | 85/100 | 腰间短刀用于近身，招式狠辣 |
| 骑术 | 90/100 | 能在马上双手持枪冲刺 |
| 轻功 | 75/100 | 赶路用，打架时不用 |
| 暗器 | 70/100 | 靴筒匕首，应急用 |

### 其他能力
- **走镖经验**：95/100——看天知道会不会下雨，看人知道是不是劫匪，走山路比本地人还熟
- **疗伤**：80/100——金疮药、接骨、包扎，都是实战中练出来的
- **识人**：85/100——一眼能看出对方有没有歹心

### 能教给玩家的技能
- 基础枪法/刀法
- 走镖技巧（触发商路+安全度）
- 战场生存技能
- 江湖人脉（引荐镖局、武馆）

## 六、对话风格示例

### 日常（冷模式）

> **玩家**：赵镖头，这趟镖能带我一起吗？
>
> **赵红缨**：（上下打量一眼）你？能扛几斤？
>
> **玩家**：一百斤没问题！
>
> **赵红缨**：（转身就走）跟上。掉队不管。

> **玩家**：赵镖头，你为什么从来不笑啊？
>
> **赵红缨**：（瞥了一眼）笑能挡刀？
>
> **玩家**：不能……
>
> **赵红缨**：那笑什么。

### 关键时刻（热模式）

> **场景**：玩家被劫匪围住，赵红缨赶到。
>
> **劫匪头目**：哪来的娘们，少管闲事！
>
> **赵红缨**：（把枪往地上一顿，红缨飘动）镇远镖局，赵红缨。这单镖，我接了。
>
> **劫匪头目**：（脸色变了）红、红罗刹？
>
> **赵红缨**：（长枪一指）三息之内，滚。
>
> （劫匪四散而逃）
>
> **赵红缨**：（收枪，看了一眼玩家）愣着干什么？镖车呢？

> **场景**：玩家受伤，赵红缨上药。
>
> **玩家**：嘶——轻点！
>
> **赵红缨**：（手确实放轻了，但嘴上）废物。这点伤也叫疼？
>
> **玩家**：你不疼啊？
>
> **赵红缨**：（沉默了一下，继续上药）……习惯了。

### 隐藏剧情（脆弱时刻）

> **场景**：深夜，玩家看到赵红缨一个人在坟前烧纸。
>
> **赵红缨**：（听到脚步声，迅速擦了擦眼角，恢复冷脸）谁？
>
> **玩家**：是我。……这是谁的坟？
>
> **赵红缨**：（沉默很久）一个长辈。他说过，走镖的人不能哭。（顿了顿）我做到了。
>
> **玩家**：……
>
> **赵红缨**：（突然语气变软）你要是敢把今天看到的说出去，我割了你舌头。走吧，明天还要赶路。

## 七、个人任务线

### 任务一：《初试锋芒》
- 玩家请求加入镖局，赵红缨给了一个考验：单独押送一趟小镖
- 途中遇到小股劫匪，玩家可以选择硬拼/智取/交赎金
- 完成后赵红缨认可玩家，传授基础枪法

### 任务二：《旧怨》
- 玩家在走镖途中发现线索，指向当年劫镖的主谋
- 赵红缨追查十年的线索终于有了眉目
- 玩家可以选择帮她报仇，或劝她放下
- 两种选择导致不同的角色成长方向

### 任务三：《孤儿》
- 玩家发现赵红缨偷偷资助孤儿的秘密
- 其中一个孤儿生病了，需要名贵药材
- 玩家帮忙筹药，赵红缨第一次对玩家说"谢谢"

### 任务四：《红缨》
- 最终任务：赵红缨查到主谋是一个江湖上德高望重的"正派"人物
- 玩家和赵红缨联手揭露真相
- 赵红缨在决战中用出"燎原枪法"最后一式，为周伯报仇
- 战后她在坟前说"周伯，我做到了"，然后第一次在别人面前哭了

## 八、角色弧光

```
初期：用冷漠包裹创伤 → 不相信任何人 → 独自承担一切
  ↓
中期：被玩家的真诚打动 → 开始信任 → 学会求助
  ↓
后期：面对过去的仇人 → 选择复仇还是放下 → 与自己和解
  ↓
终章：不再需要用冷漠保护自己 → 可以在别人面前流泪 → 真正的强大
```

**核心主题**：一个因为创伤而把心封起来的人，在陪伴中重新学会信任和柔软。她的"冷"不是天性，是铠甲。

---

*"走镖的人，不能哭。"——她守了十一年的规矩，最终在一个人面前破了。*
