## 三、新增/完善的核心系统

### 3.1 AShanHeHUD（新增）
- 负责游戏内 HUD Widget 的创建和管理
- SetHUDVisible 显隐控制
- 蓝图可配置 HUDWidgetClass

### 3.2 AShanHePlayerController（完善）
- **OnMove**：WASD 移动（基于控制器朝向的前后左右）
- **OnLook**：鼠标视角旋转（Yaw/Pitch）
- **OnInteract**：射线检测前方 300cm 可交互物体
- **OnOpenMenu**：菜单切换接口
- **OnTimeScale**：时间流速调整接口
- Enhanced Input 系统集成

### 3.3 AShanHeGameState（完善）
- **GetCurrentSeason**：春夏秋冬季节计算（农历月份对应）
- **GetCurrentSolarTerm**：二十四节气计算（每月两节气）
- **GetFormattedDate**：格式化日期字符串（如"统一1368年1月1日"）
- **GetSeasonName/GetSolarTermName**：中文名称输出
- 时间推进系统（AdvanceDays）

### 3.4 AShanHeCharacter（完善）
- **生命值系统**：Health/MaxHealth，ApplyDamage/Heal
- **体力系统**：Stamina/MaxStamina，ConsumeStamina/RestoreStamina
- **饥饿值**：Hunger
- **金钱**：Money
- **IsAlive**：存活状态检查
- **Interact**：前方 200cm 射线交互
- **BeginPlay**：角色进入世界日志

### 3.5 存档系统（完善）
- **SaveGame**：保存玩家属性（生命/体力/年龄/金钱）+ 世界时间 + 元数据
- **LoadGame**：恢复玩家状态 + 世界时间 + 旧存档自动迁移
- **版本化存档**：SaveVersion=2，支持 v1→v2 迁移
- **存档摘要**：玩家名/朝代/日期/游戏时长
- **完整性验证**：IsValid 检查

### 3.6 AShanHeGameMode（完善）
- DefaultPawnClass = AShanHeCharacter
- HUDClass = AShanHeHUD
- PlayerControllerClass = AShanHePlayerController
- GameStateClass = AShanHeGameState
- 背景音乐自动播放（MainTheme）
- 时间推进系统（Tick 驱动）
