# 山河纪元 · 游戏平衡设计文档

## 概述

本文档定义全系统数值平衡规则，包括经济曲线、战斗数值、成长曲线、难度曲线等。所有数值均可通过 DataConfigSystem 调整，支持 Mod。

---

### 1.3 粮价公式

```
基础粮价 = 10 文/斤
供需系数 = 供应量 / 需求量
季节系数 = 1.0 + 0.3 * sin(月份 * PI / 6)  // 秋收最低，春荒最高
天灾系数 = 1.0 + 天灾严重度 * 2.0
战乱系数 = 1.0 + 战乱等级 * 0.5

最终价格 = 基础粮价 * 季节系数 * 天灾系数 * 战乱系数 / 供需系数
```

**平衡目标**：
- 正常年景：粮价 8-15 文/斤，普通家庭可承受
- 灾年：粮价 30-50 文/斤，普通家庭难以承受，触发流民
- 战乱：粮价 20-40 文/斤，同时收入下降

**平衡目标**：

## 二、战斗系统平衡

### 2.1 属性与战斗数值换算

| 属性 | 每点加成 | 上限 |
|------|---------|------|
| 力量 | +2 攻击力, +5 负重 | 20（凡人极限） |
| 敏捷 | +1% 闪避, +1% 暴击 | 20 |
| 体质 | +10 生命值, +1 体力恢复 | 20 |
| 智力 | +1% 技能效果, +1% 识破 | 20 |
| 勇气 | +1% 士气, +1% 暴击伤害 | 20 |
| 运气 | +0.5% 暴击, +0.5% 闪避 | 20 |

### 2.2 生命值与伤害

```
基础生命值 = 100 + 体质 * 10
基础攻击力 = 10 + 力量 * 2 + 武器攻击
基础防御力 = 体质 * 1 + 护甲防御
实际伤害 = (攻击力 - 防御力 * 0.5) * (1 - 闪避率) * 暴击倍率
暴击倍率 = 1.5 + 勇气 * 0.05
```

**平衡目标**：
- 普通农民（力量5，体质5）：HP 150，攻击 20，防御 5
- 普通士兵（力量10，体质10）：HP 200，攻击 30，防御 10
- 精锐士兵（力量15，体质15）：HP 250，攻击 40，防御 15
- 顶级武将（力量20，体质20）：HP 300，攻击 50，防御 20
- 玩家 vs 普通士兵：3-5 招解决
- 玩家 vs 顶级武将：需要策略/装备/等级

### 2.3 武器平衡

| 武器类型 | 攻击 | 攻速 | 暴击 | 特殊效果 |
|---------|------|------|------|---------|
| 短剑 | 15 | 快（1.0s） | 10% | 灵活，适合连击 |
| 长剑 | 25 | 中（1.5s） | 8% | 平衡型 |
| 大刀 | 40 | 慢（2.5s） | 5% | 高伤害，破甲 |
| 长枪 | 30 | 中（1.8s） | 7% | 攻击距离远 |
| 弓箭 | 20 | 中（2.0s） | 12% | 远程，需要弹药 |
| 弩 | 35 | 慢（3.0s） | 15% | 远程高伤，装填慢 |

### 2.4 士气系统

```
基础士气 = 50 + 勇气 * 2
士气影响：
  > 80: 攻击+20%, 防御+10%
  60-80: 正常
  40-60: 攻击-10%
  20-40: 攻击-20%, 可能溃逃
  < 20: 必然溃逃
```

**士气变化因素**：
- 击杀敌人：+5
- 队友死亡：-10
- 己方伤亡过半：-20
- 将领阵亡：-30
- 援军到达：+15
- 胜利：+20

## 三、角色成长曲线

### 3.1 经验与等级

| 等级 | 所需经验 | 累计经验 | 属性点 |
|------|---------|---------|--------|
| 1 | 0 | 0 | 0 |
| 5 | 500 | 1000 | 2 |
| 10 | 2000 | 7500 | 5 |
| 20 | 8000 | 60000 | 10 |
| 30 | 20000 | 200000 | 15 |
| 50 | 50000 | 1000000 | 25 |
| 100 | 200000 | 8000000 | 50 |

**经验获取**：
- 击杀普通敌人：10-50
- 完成任务：100-1000
- 技能练习：1-10/次
- 读书学习：5-20/小时

**平衡目标**：
- 新手期（1-10级）：快速成长，每小时升 2-3 级
- 成长期（10-30级）：稳步成长，每小时升 1 级
- 成熟期（30-50级）：缓慢成长，需要专注方向
- 巅峰期（50+级）：极难提升，追求极致

### 3.2 技能成长

| 技能等级 | 所需练习 | 效果加成 |
|---------|---------|---------|
| 入门（1-20） | 100次 | 基础效果 |
| 熟练（21-50） | 500次 | +20% 效果 |
| 精通（51-80） | 2000次 | +50% 效果 |
| 大师（81-99） | 10000次 | +100% 效果 |
| 宗师（100） | 特殊事件 | 独特能力 |

## 四、难度曲线

### 4.1 区域难度

| 区域 | 推荐等级 | 敌人强度 | 奖励倍率 |
|------|---------|---------|---------|
| 新手村 | 1-5 | 弱 | 1.0x |
| 县城周边 | 5-15 | 中 | 1.2x |
| 州府 | 15-30 | 中强 | 1.5x |
| 边疆 | 20-40 | 强 | 2.0x |
| 战场 | 30-50 | 很强 | 2.5x |
| 秘境 | 40+ | 极强 | 3.0x |

### 4.2 时间难度

- **游戏前期（0-5年）**：世界相对和平，玩家成长空间大
- **游戏中期（5-15年）**：矛盾积累，可能爆发战争/灾荒
- **游戏后期（15-30年）**：王朝周期，改朝换代可能
- **游戏晚期（30+年）**：玩家年老，传承给后代

## 六、平衡性测试清单

### 6.1 经济测试
- [ ] 农民角色能否在正常年景维持温饱
- [ ] 灾年是否会导致大量流民
- [ ] 商人是否有合理的利润空间
- [ ] 是否存在无限刷钱的漏洞
- [ ] 通货膨胀是否在可控范围

### 6.2 战斗测试
- [ ] 同等级玩家 vs NPC 是否平衡
- [ ] 武器类型之间是否有明显优劣
- [ ] 士气系统是否合理
- [ ] 群战是否有策略性
- [ ] 玩家是否可以靠操作越级挑战

### 6.3 成长测试
- [ ] 前期成长是否有成就感
- [ ] 后期是否有追求目标
- [ ] 不同路线成长速度是否合理
- [ ] 是否存在最优解路线
- [ ] 多代传承是否平滑

### 6.4 AI 测试
- [ ] NPC 是否会做出合理决策
- [ ] 世界模拟是否稳定运行
- [ ] 是否出现 NPC 全部死亡/破产的情况
- [ ] 王朝周期是否在合理时间内
- [ ] 玩家行为是否能影响世界

## 七、可调参数汇总

所有参数均可在 `Content/Config/` 目录下的 DataTable 中调整：

| 配置文件 | 内容 |
|---------|------|
| EconomyBalance.csv | 物价、收入、税率、货币兑换 |
| CombatBalance.csv | 属性换算、武器数值、士气公式 |
| GrowthBalance.csv | 经验曲线、技能成长、属性点 |
| DifficultyBalance.csv | 区域难度、时间难度、AI 强度 |
| AIBalance.csv | NPC 能力分布、决策权重 |

**Mod 支持**：Mod 可以覆盖这些配置文件，实现完全自定义的平衡调整。
