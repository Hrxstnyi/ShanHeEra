# 宫廷角色群像 — 完整人设与宫廷斗争线

## 一、皇帝：萧承乾

### 基本信息
| 项目 | 内容 |
|------|------|
| 姓名 | 萧承乾 |
| 年号 | 承平 |
| 年龄 | 出场42岁 |
| 身份 | 当朝天子 |
| 性格标签 | 多疑、勤政、内心孤独、晚年昏聩 |

### 外貌
- 中等身材，因常年伏案而微驼
- 面容清癯，颧骨高，眼神锐利但带着疲惫
- 留短须，已斑白
- 常穿暗黄龙袍，不喜欢奢华
- 走路很慢，但每一步都很稳

### 性格核心
**一个想做好皇帝但被皇权吞噬的人**
- 勤政：每天批奏折到深夜，二十年如一日
- 多疑：因为皇位是从兄弟手中夺来的，不信任任何人
- 内心孤独：身边没有可以说真话的人
- 晚年变化：随着年龄增长，开始追求长生，宠信方士，朝政渐乱

### 背景故事
萧承乾是先帝第三子，本无资格继位。先帝晚年，太子与二皇子争位，两败俱伤。他在权臣支持下登基，改元承平。

登基初期，他励精图治，整顿吏治，轻徭薄赋，开创了"承平之治"。但随着权力稳固，他的多疑性格逐渐暴露——清洗了当年支持他的权臣，建立了庞大的密探网络。

他有三个儿子，但始终没有立太子，因为他怕太子势力坐大威胁自己。

### 与玩家的互动
- 玩家做官到一定级别可以面圣
- 皇帝会根据玩家的派系和能力给出不同任务
- 玩家可以选择：做忠臣（直言进谏，可能被贬）、做权臣（结党营私）、做能臣（办实事，不站队）
- 晚年皇帝会开始猜忌玩家，玩家需要做出选择

### 经典台词
1. "朕坐拥天下，却连一个可以信任的人都没有。"
2. "你说的是真话？……真话最伤人。"
3. "太子？朕还没死呢。"
4. "这江山，朕守了二十年，还能守几年？"

## 二、太子：萧景琰

### 基本信息
| 项目 | 内容 |
|------|------|
| 姓名 | 萧景琰 |
| 年龄 | 出场22岁 |
| 身份 | 皇长子（未正式立储） |
| 性格标签 | 仁厚、优柔寡断、理想主义、缺乏政治手腕 |

### 外貌
- 高大俊朗，眉目间有书卷气
- 常穿青色常服，不喜欢太子冠服
- 手指修长，因为常年读书写字
- 笑起来很温暖，但很少笑

### 性格核心
**一个好人，但不一定是好皇帝**
- 仁厚：对下属宽厚，经常为犯错的人求情
- 优柔寡断：做决定时总是犹豫，怕得罪人
- 理想主义：相信儒家的仁政理想，不理解政治的黑暗
- 内心挣扎：知道自己不够强势，但又不想变成父亲那样的人

### 背景故事
萧景琰是皇帝的长子，母亲是已故皇后。他从小被当作继承人培养，师从当世大儒。但皇帝迟迟不立他为太子，让他始终处于不安之中。

他在朝堂上没有自己的势力，因为他不屑于结党。这导致他在政治斗争中屡屡被动。

### 与玩家的互动
- 玩家可以选择辅佐太子，帮他建立势力
- 太子会给玩家一些"仁政"任务（赈灾、减税、平反冤案）
- 如果玩家走权臣路线，可以利用太子的优柔寡断
- 最终结局：太子可能顺利继位（仁君）、被废（悲剧）、或在玩家帮助下成长为合格的君主

### 经典台词
1. "父皇说我太仁厚，可仁厚有错吗？"
2. "我不想做一个连自己人都保不住的太子。"
3. "如果当皇帝就要变成父皇那样，我宁愿不当。"

## 三、公主：萧灵月

### 基本信息
| 项目 | 内容 |
|------|------|
| 姓名 | 萧灵月 |
| 年龄 | 出场18岁 |
| 身份 | 皇帝最宠爱的公主 |
| 性格标签 | 聪慧、叛逆、有政治头脑、向往自由 |

### 外貌
- 明艳动人，眼睛很大很亮
- 喜欢穿男装出宫，穿女装时惊艳众人
- 腰间常挂一把短剑（皇帝特许）
- 走路轻快，像一阵风

### 性格核心
**被困在金丝笼里的鹰**
- 聪慧：过目不忘，对政治有敏锐的洞察力
- 叛逆：不喜欢宫廷规矩，经常偷偷出宫
- 有政治头脑：比太子更懂权谋，但因为是女儿身无法参与朝政
- 向往自由：梦想着像普通人一样生活

### 背景故事
萧灵月是皇帝最小的女儿，母亲是宠妃。她从小聪明过人，皇帝破例让她和皇子们一起读书。她的才学甚至超过了几位皇子。

但随着年龄增长，她意识到自己的命运——要么和亲，要么嫁给权臣。她不甘心，开始暗中培养自己的力量。

### 与玩家的互动
- 玩家可能在宫外偶遇微服的公主
- 公主会给玩家一些"不可能的任务"（帮她出宫、帮她传递消息）
- 玩家可以选择：帮她争取自由、利用她的身份、或成为她的知己
- 有隐藏感情线（但需要极高好感和特定条件）

### 经典台词
1. "凭什么男儿可以征战天下，女儿只能深宫绣花？"
2. "你以为我想当公主？我宁愿做个江湖侠客。"
3. "这宫里的人，个个戴着面具，你也不例外。"
4. "帮我一个忙……别告诉父皇我出来了。"

## 四、大太监：魏忠贤（化名）

### 基本信息
| 项目 | 内容 |
|------|------|
| 姓名 | 魏德海 |
| 年龄 | 出场55岁 |
| 身份 | 司礼监掌印太监，皇帝最信任的人 |
| 性格标签 | 城府极深、八面玲珑、有底线、知恩图报 |

### 外貌
- 白面无须，声音尖细但不刺耳
- 总是笑眯眯的，眼睛眯成一条缝
- 走路无声，像猫一样
- 手指保养得很好，戴着玉扳指

### 性格核心
**最懂皇权的人，也是最危险的人**
- 城府极深：在宫中三十年，历经三朝而不倒
- 八面玲珑：对谁都客客气气，但谁都摸不透他
- 有底线：不害忠良，不扰百姓，只在政治斗争中出手
- 知恩图报：对有恩于他的人会暗中相助

### 背景故事
魏德海9岁净身入宫，从最底层的洒扫太监做起。他亲眼见过太多宫廷倾轧，学会了在夹缝中生存。

他在皇帝还是皇子时就跟随他，是皇帝潜邸旧人。皇帝登基后，他成为司礼监掌印，批红之权在握。

他不是传统意义上的"权阉"——他不贪财不好色，唯一的追求就是权力本身。但他也知道，权力是皇帝给的，皇帝随时可以收回。

### 与玩家的互动
- 魏德海是玩家在宫廷中最重要的信息来源
- 他会给玩家一些"不能明说"的暗示
- 玩家可以选择：与他合作（获得情报和保护）、与他为敌（极难）、保持距离
- 他有一条隐藏的报恩线——如果玩家的父亲曾对他有恩，他会格外关照玩家

### 经典台词
1. "奴才这辈子，只懂一个道理——伴君如伴虎。"
2. "大人，有些话，奴才不能说，但您可以自己悟。"
3. "这宫里啊，死的最惨的，往往是聪明人。"
4. "皇上让奴才看着您……奴才什么都没看见。"

| 年龄 | 出场28岁 |
| 身份 | 贵妃，公主生母 |
| 性格标签 | 表面温婉、实际精明、护犊情深、政治高手 |

### 外貌
- 绝色，肌肤胜雪
- 总是淡妆，不施粉黛也压群芳
- 眼神温柔，但深处藏着算计
- 走路姿态优雅，像弱柳扶风

### 性格核心
**用温柔做武器的女人**
- 表面温婉：对谁都和和气气，从不发脾气
- 实际精明：在后宫争斗中从未失手
- 护犊情深：为了女儿可以做任何事
- 政治高手：通过影响皇帝来影响朝政，但从不留下痕迹

### 背景故事
苏婉容出身江南书香门第，通过选秀入宫。她不争宠，但皇帝偏偏最宠她。因为她懂皇帝——知道他什么时候需要倾听，什么时候需要安静。

她有一个女儿（公主），她最大的心愿是让女儿能自由选择人生，而不是成为政治筹码。为此，她在暗中布局。

### 与玩家的互动
- 贵妃是宫廷中少数可以"说上话"的人
- 她会通过公主向玩家传递请求
- 玩家可以选择：帮她保护公主（获得她的支持）、拒绝（得罪她）
- 她是宫廷斗争线的关键人物——她的支持可以决定很多事

### 经典台词
1. "这后宫里，最不缺的就是女人，最缺的是真心。"
2. "我不求什么，只求月儿能平安快乐。"
3. "皇上是天子，但也是个可怜人。"
4. "大人，有些事，比官位更重要。"

## 宫廷斗争线总览

### 三大势力

| 势力 | 核心人物 | 目标 | 特点 |
|------|---------|------|------|
| **太子党** | 萧景琰 + 儒家大臣 | 拥立太子，推行仁政 | 理想主义，缺乏实权 |
| **二皇子党** | 萧景桓 + 军方将领 | 夺嫡，以武治国 | 有兵权，行事强硬 |
| **帝党** | 皇帝 + 魏德海 | 维持皇权平衡 | 最强，但内部不稳 |

### 玩家在宫廷斗争中的位置

1. **入局**：玩家做官到五品以上，会被各方势力拉拢
2. **选边**：可以加入太子党/二皇子党/帝党，或保持中立
3. **斗争**：通过奏折、弹劾、联姻、暗杀等手段进行政治斗争
4. **结局**：
   - 太子党胜 → 仁君登基，玩家成为首辅
   - 二皇子党胜 → 武夫当国，玩家成为兵马大元帅
   - 帝党胜 → 维持现状，玩家成为皇帝心腹
   - 玩家自立 → 谋反线（极难）

### 关键事件
- **议储之争**：皇帝病重，各方争夺太子之位
- **国本之争**：太子被废，玩家需要决定是否营救
- **宫变之夜**：二皇子发动政变，玩家的选择决定结局
- **新帝登基**：新帝上位，论功行赏或清算旧臣
