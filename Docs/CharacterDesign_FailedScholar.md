# 角色人设 · 文必正（落第书生）

> "子曰：学而时习之，不亦说乎——哎哎哎你别走啊！我还没解释'说'通'悦'呢！"
> "……哼，燕雀安知鸿鹄之志哉！（小声）虽然我这鸿鹄考了二十年还没中举……"

## 二、外貌描写

### 整体形象
身高一米七，瘦得像根竹竿，永远佝偻着背（长年低头看书的缘故）。走路时低着头，嘴里念念有词，经常撞到人或柱子，然后鞠躬道歉"对不住对不住，子曰……"

### 面部
- 长脸，颧骨高，眼睛很小但很亮（谈到学问时会发光）
- 留着两撇小胡子，经常因为思考而捻胡子，把胡子捻得乱七八糟
- 面色苍白（长年不见太阳），有明显的黑眼圈
- 额头上有一个包（经常撞门撞的）

### 穿着
- 永远穿着一件洗得发白的青色长衫，袖口磨破了也舍不得换
- 腰间系着一根布带，别着一支毛笔和一个墨盒
- 脚上是布鞋，左脚的鞋有个洞（"这叫通风透气，圣人云……"）
- 头发用木簪挽着，经常有碎发掉下来，他会用嘴吹开

### 标志性物品
- **翻烂的书**：永远抱着一本《论语集注》，书角全卷了，页边写满了批注，有的页甚至掉了用线缝着
- **墨盒**：一个旧铜墨盒，里面的墨都干了，但他还是带着，"万一有人需要题字呢"
- **酒葫芦**：虽然是书生，但爱喝酒，而且酒量极差，一口就醉，醉了就开始背《离骚》

## 三、性格特质

### 核心性格：迂腐可笑 + 大是大非坚定

| 表面 | 内里 |
|------|------|
| 满口之乎者也，酸腐气十足 | 真正的学问扎实，只是不适合科举 |
| 经常闹笑话，被人嘲笑 | 被嘲笑也不生气，继续我行我素 |
| 看起来软弱可欺 | 在大是大非面前异常坚定，不怕死 |
| 自命不凡，觉得自己怀才不遇 | 内心深处其实知道自己不适合做官，但不甘心 |
| 贪小便宜，蹭吃蹭喝 | 对朋友极其大方，有钱了全请客 |

### 性格细节

**迂腐的一面：**
- 说话必引经据典，哪怕是点菜也要"子曰：食不厌精"
- 走路要走"君子步"，结果走得比乌龟还慢
- 看到不合礼法的事就要上前说教，经常被人打
- 坚持"君子远庖厨"，但吃肉比谁都香

**坚定的一面：**
- 贪官要他做伪证，他宁死不从，"士可杀不可辱"
- 灾年时把自己仅有的粮食拿出来煮粥，自己饿肚子
- 有人欺负百姓，他手无缚鸡之力也要冲上去理论
- 他教的学生如果有人考上了，他比自己中举还高兴

### 口头禅
- "子曰……"（开头必说，然后开始跑题）
- "非也非也！"（纠正别人时）
- "燕雀安知鸿鹄之志哉！"（被嘲笑时）
- "待我算一算……"（然后开始掰手指头，算半天算不对）
- （认真时）"读书人，有所为，有所不为。"

## 四、背景故事

### 出身
文必正出身于苏州的一个书香门第，父亲是个举人，在他十岁时病逝。家道中落，母亲靠织布供他读书。他从小就是神童，十二岁中秀才，所有人都觉得他将来必中状元。

### 转折：二十年落第
然而从二十岁第一次参加乡试开始，他连续考了二十年，次次落榜。不是学问不够，而是他的文章太"怪"——他喜欢在文章里针砭时弊，考官不喜欢。

二十年过去了，当年和他一起考的人有的已经做了大官，有的已经去世，只有他还在考。别人都叫他"文疯子"，他自己也知道，但就是放不下。

### 现在
他在苏州开了个私塾，教几个小孩读书，勉强糊口。学生不多，因为他教的东西不适合科举（他教的是真学问，不是应试技巧）。但他教出来的学生，人品都很好。

他和苏忘机是忘年交——一个是老顽童匠师，一个是落第书生，经常在一起喝酒抬杠，是游戏里的喜剧担当组合。

### 隐藏线
- 他的文章其实被一位主考官赏识过，但那位主考官被排挤了，没能录取他
- 他有一个学生后来中了状元，但那个学生在朝堂上被人陷害，他一直在想办法营救
- 他写的一本书被禁了，因为里面批评了朝政，但民间偷偷流传

## 五、技能与能力

### 学问
| 技能 | 等级 | 说明 |
|------|------|------|
| 经学 | 95/100 | 四书五经倒背如流，有自己的见解 |
| 史学 | 90/100 | 历朝历代的兴衰了如指掌 |
| 文学 | 88/100 | 诗词文章都写得好，就是不适合科举 |
| 策论 | 85/100 | 分析时政一针见血，但太尖锐 |
| 书法 | 80/100 | 一手好字，卖字能换酒钱 |

### 其他
- **口才**：70/100——讲道理时一套一套的，但吵架时容易激动说不出话
- **识人**：85/100——读书人看人心很准
- **理财**：10/100——钱从来留不过三天

### 能教给玩家的
- 科举应试技巧（虽然他自己考不上，但他知道怎么"迎合考官"）
- 经史学问（增加学识属性）
- 写文章/写状纸/写书信
- 官场规则（他虽然没当过官，但看得透）

## 六、对话风格示例

### 日常（迂腐模式）

> **玩家**：文先生，今天吃了吗？
>
> **文必正**：（摇头晃脑）子曰：食不厌精，脍不厌细。我今日吃的是——（掏了掏口袋）半个馒头。圣人云，一箪食一瓢饮，在陋巷，人不堪其忧，回也不改其乐……
>
> **玩家**：所以你是没吃饱？
>
> **文必正**：（脸一红）非也非也！这叫……这叫安贫乐道！对，安贫乐道！

> **玩家**：文先生，你考了二十年都没中，有没有想过放弃？
>
> **文必正**：（突然正色）放弃？子曰：譬如为山，未成一篑，止，吾止也。譬如平地，虽覆一篑，进，吾往也！意思就是——
>
> **玩家**：意思是你还要继续考？
>
> **文必正**：（泄气）……对。

### 关键时刻（坚定模式）

> **场景**：贪官要文必正做伪证陷害一个清官。
>
> **贪官**：文先生，只要你写一份证词，这五十两银子就是你的。
>
> **文必正**：（看着银子，咽了口唾沫，然后摇头）不义而富且贵，于我如浮云。
>
> **贪官**：你可想好了，不写的话，你这私塾就别想开了。
>
> **文必正**：（第一次没有引经据典，声音很平静）读书人，有所为，有所不为。你杀了我，我也不写。
>
> **贪官**：你——！
>
> **文必正**：（虽然腿在抖，但站得笔直）人生自古谁无死？留取丹心照汗青。（小声）这是文丞相的诗，我虽然不姓文，但也想试试。

### 喜剧时刻

> **场景**：文必正喝醉了。
>
> **文必正**：（站在桌子上）帝高阳之苗裔兮，朕皇考曰伯庸——！
>
> **玩家**：文先生你下来，危险！
>
> **文必正**：（挥手）不！我不下来！我文必正，二十年来——（打了个嗝）二十年来寒窗苦读，竟然不如一个会拍马屁的！苍天无眼啊——！（一脚踩空，摔下来）

## 七、个人任务线

### 任务一：《私塾先生》
- 玩家想学文化，找到文必正
- 他要求玩家先帮他招几个学生（私塾快开不下去了）
- 玩家帮忙后，他开始教玩家读书

### 任务二：《第二十一次》
- 又到了乡试之年，文必正准备第二十一次参加
- 玩家帮他准备，途中发现他的文章确实写得好，但太尖锐
- 玩家可以选择劝他改文风迎合考官，或支持他坚持自己
- 两种选择导致不同结果（改了可能中举但失去自我，不改继续落第但赢得尊重）

### 任务三：《禁书》
- 玩家发现文必正写了一本批评朝政的书，被官府通缉
- 玩家可以选择帮他藏书，或劝他自首，或帮他修订
- 这本书后来在民间流传，影响深远

### 任务四：《状元学生》
- 文必正的一个学生中了状元，但在京城被陷害
- 文必正第一次离开江南，前往京城营救
- 玩家陪同，在京城的朝堂斗争中，文必正用他的学问和口才扭转局面
- 最终学生获救，文必正被皇帝赏识，想要封官，但他拒绝了
- "臣的学问在民间，不在朝堂。"

### 任务五：《不第居士》
- 文必正终于放下了科举，把精力放在教书和著书上
- 他的私塾变成了江南最有名的书院
- 临终前，他对玩家说"我这辈子没中举，但我教出了比状元更好的学生。值了。"

## 八、角色弧光

```
初期：执着于科举 → 用"怀才不遇"定义自己 → 酸腐可笑
  ↓
中期：发现科举不是唯一的路 → 开始怀疑自己的坚持 → 迷茫
  ↓
后期：在更大的舞台上证明自己 → 明白学问的真正价值 → 释然
  ↓
终章：放下执念 → 成为真正的"先生" → 影响一代人
```

**核心主题**：一个被科举制度困住的读书人，最终发现人生的价值不在于功名，而在于传承和良知。他的"迂腐"是对学问的敬畏，他的"可笑"是对理想的坚持。

---

*"二十年来寒窗苦，不第何妨做先生。"——文必正，三十八岁，终于想通了*
