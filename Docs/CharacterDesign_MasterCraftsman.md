> "……哎你别走啊，老夫还没说完呢——这把刀，你拿反了。"

## 二、外貌描写

### 整体形象
身高约一米六五，干瘦但精神矍铄。永远佝偻着背，像是在低头看地上的蚂蚁，但一双眼睛亮得像藏了星星。走路时脚步很轻，像猫一样，经常悄无声息地出现在别人身后吓人一跳。

### 面部
- 满脸皱纹，但每道皱纹里都像是藏着笑意
- 眼睛很小，笑起来眯成一条缝，但认真时会突然睁大，目光如电
- 留着一撮山羊胡，经常被糖稀粘住几根
- 缺了一颗门牙（据说是年轻时打铁被火星崩的，他自己说是吃糖葫芦磕的）
- 左耳戴了一只小小的铜环（来历是个谜）

### 穿着
- 永远穿着一件洗得发白的灰蓝色粗布短打，袖口和膝盖处全是补丁
- 腰间系着一条油光发亮的牛皮围裙，上面插满了各种小工具：凿子、锉刀、小锤子、镊子、还有一根糖葫芦
- 脚上穿着一双自己纳的布鞋，鞋底比常人厚三倍（"站得稳才能打得铁"）
- 冬天会加一件油渍斑斑的羊皮袄，夏天就光膀子，露出一身精瘦的肌肉和伤疤

### 标志性物品
- **糖葫芦**：永远拿着一根，吃完一根立刻去村口张老头那里再买一根。他说"打铁需要糖分，没糖打不动铁"
- **老茧**：双手布满老茧，右手食指和拇指的老茧厚得像硬币，那是六十年握锤的痕迹
- **小铁锤**：一把巴掌大的小铁锤，锤柄被磨得锃亮，据说是他师父传给他的，比他命还重要
- **缺指**：左手小指缺了半截（年轻时为了救一个孩子被机器轧的，他从不主动提）

## 三、性格特质

### 核心性格：童真 + 靠谱的矛盾统一

| 表面 | 内里 |
|------|------|
| 贪吃、贪玩、爱恶作剧 | 心思缜密，观察力惊人 |
| 说话颠三倒四，经常跑题 | 关键时刻一针见血，从不说废话 |
| 跟小孩抢糖葫芦 | 对弱者有极强的保护欲 |
| 看起来不靠谱、疯疯癫癫 | 做事情极其认真，追求极致 |
| 什么都不在乎的样子 | 把承诺看得比命重 |

### 性格细节

**孩子气的一面：**
- 跟村里的小孩玩弹珠、捉迷藏，还耍赖
- 看到新奇的小玩意儿会眼睛发光，像个孩子
- 生气了会撅嘴，好的时候会哼小曲
- 喜欢恶作剧，比如在别人凳子上放个小石子，然后躲在旁边偷笑
- 吃糖葫芦时会先舔半天，舍不得咬

**靠谱的一面：**
- 答应别人的事，拼了命也要做到
- 村里谁家农具坏了，他免费修，从不收钱
- 灾年时，他把自己存的粮食全拿出来，自己去挖野菜
- 教徒弟时极其严格，一个动作不对就重来一百遍
- 遇到大事时，他是全村最镇定的人，说话声音不大但所有人都听他的

### 口头禅
- "哎呀呀，这个有意思！"
- "老夫说了你也不懂，等你到了我这个年纪就明白了……哎你别走啊！"
- "这事儿吧，说简单也简单，说难也难……（开始跑题）"
- "吃糖葫芦不？不吃？不吃我吃了啊。"
- （认真时）"听好了，这话我只说一遍。"

## 四、背景故事

### 前半生：京城名匠
苏忘机出身于苏州的工匠世家，祖上三代都是将作监的匠人。他从小就是天才，十二岁就能独立打造农具，十五岁被选入将作监，二十岁成为将作监最年轻的主簿。

他参与过皇宫的修缮、皇陵的建造、火器的研发。三十岁时已经是"天下第一名匠"，王公贵族都以拥有一件他打造的器物为荣。

### 转折：四十岁那年
四十岁时，他奉命打造一批兵器。他发现这批兵器的用料被人克扣，如果按标准打造，兵器会在战场上断裂。他向上级举报，反而被诬陷"偷工减料"，打入大牢。

在牢里待了三年，后来被一个老同僚保出来。出来后，他发现自己的妻子已经病逝，儿子不知所踪。他心灰意冷，离开了京城，隐姓埋名来到青溪镇，一待就是三十二年。

### 在青溪镇的日子
他在村头开了个铁匠铺，说是铁匠铺，其实什么都修：农具、锅碗瓢盆、小孩的玩具、甚至村里的老水车。他不收钱，村民过意不去就给他送些吃的，他最爱的就是张老头的糖葫芦。

村民都知道他是个怪人，但也是个好人。没人知道他的过去，他也从不提。直到玩家的出现，才慢慢揭开他的故事。

### 隐藏身份（彩蛋）
- 他是当朝首辅的恩师（首辅年轻时曾跟他学过三个月木工）
- 他参与设计了现在的京城城墙
- 他的儿子还活着，在西域做商队护卫（后续剧情线）
- 他年轻时曾救过一个孩子，那个孩子后来成为了名将（精忠报国彩蛋的关联人物）

## 五、技能与能力

### 工匠技能（满级）
| 技能 | 等级 | 说明 |
|------|------|------|
| 锻造 | 100/100 | 能打造出游戏中最好的兵器和农具 |
| 木工 | 95/100 | 建筑、家具、车船，无所不能 |
| 机关术 | 90/100 | 能制作精巧的机关装置（连弩、自动水车等） |
| 冶金 | 92/100 | 掌握多种合金配方，包括失传的技艺 |
| 雕刻 | 88/100 | 木雕、石雕、玉雕，栩栩如生 |
| 造船 | 85/100 | 能造海船（郑和宝船级别的技术传承者） |

### 隐藏技能
- **火器制造**：90/100（两弹一星彩蛋的历史呼应——古代版的"隐姓埋名铸重器"）
- **医术**：70/100（会用草药处理外伤，年轻时在牢里跟一个老医学的）
- **武功**：60/100（不是高手，但身体硬朗，几个壮汉近不了身）

### 能教给玩家的技能
- 基础锻造/木工/雕刻
- 高级合金配方（需要好感度达到一定程度）
- 机关术（需要完成他的个人任务线）
- 造船术（需要触发"郑和下西洋"彩蛋线）
- 人生哲理（通过对话获得特质和属性加成）

## 六、对话风格示例

### 日常对话（装糊涂模式）

> **玩家**：苏大爷，您知道这附近哪里能买到好铁吗？
>
> **苏忘机**：（正在啃糖葫芦）铁？什么铁？哦——铁啊！这个嘛……你看今天天气真好，适合吃糖葫芦。你吃不吃？张老头今天的糖葫芦糖稀熬得特别好，山楂也大，就是有一颗有点虫眼……哎你别走啊！铁在铁匠铺里啊！你身后不就是铁匠铺吗！

> **玩家**：苏大爷，您年轻的时候是做什么的？
>
> **苏忘机**：（突然停下啃糖葫芦的动作，愣了一下，然后笑了）年轻的时候啊……年轻的时候老夫比你还能吃糖葫芦！一天能吃十根！（继续啃）

### 关键时刻（认真模式）

> **场景**：灾年，村里断粮，村民们绝望。
>
> **苏忘机**：（站在村口的老槐树下，手里没有糖葫芦，表情前所未有的严肃）都听好了。哭没用，怕也没用。我存了三石粮食，在我铺子的地窖里。先给老人和孩子吃。青壮的跟我去后山挖野菜，我知道哪里有。
>
> **村民**：苏大爷，那您自己……
>
> **苏忘机**：（摆摆手）老夫活了七十二年，饿过的肚子比你们吃过的饭还多。死不了。（顿了顿）记住，只要还有一口气，就不能放弃。这是我师父告诉我的，现在我告诉你们。

> **场景**：玩家被人欺负，苏忘机出现。
>
> **恶霸**：老头，少管闲事！
>
> **苏忘机**：（慢悠悠地走过来，手里还拿着糖葫芦）哎呀呀，这么多人欺负一个孩子，羞不羞啊？
>
> **恶霸**：老东西，找打！（挥拳）
>
> **苏忘机**：（侧身一闪，手里的小铁锤不知什么时候已经敲在了恶霸的手腕上，动作快得看不清）哎哟，不好意思，手滑了。（咬了一口糖葫芦）下次手可能就不滑了。

### 传授技艺时

> **苏忘机**：（把一把铁锤塞给玩家）来，打一下我看看。
>
> **玩家**：（打了一下）
>
> **苏忘机**：（摇头）不行不行，手腕太软，腰没发力，脚也没站稳。你这不是打铁，是给铁挠痒痒。
>
> **玩家**：那该怎么打？
>
> **苏忘机**：（突然正色，声音低沉）听好了。打铁不是用手打的，是用心打的。你心里想着这把铁要变成什么，它就会变成什么。心不正，铁就不正。心不诚，铁就不坚。这道理，跟做人一样。（说完又恢复嬉皮笑脸）当然了，手腕也要有力气，不然心再诚也白搭。来，再打一万下。

### 隐藏剧情对话（揭开过去）

> **玩家**：苏大爷，我在您铺子底下发现了这个。（拿出一枚将作监的令牌）
>
> **苏忘机**：（看到令牌，手里的糖葫芦掉在了地上，愣了很久，然后慢慢捡起来，擦了擦）……你从哪儿找到的？
>
> **玩家**：地窖的暗格里。
>
> **苏忘机**：（沉默了很久，然后叹了口气）唉，藏了三十二年，还是被你找到了。（第一次用非常平静的语气）坐下吧，孩子。有些事，老夫也该说了……

## 七、个人任务线

### 任务一：《糖葫芦与铁锤》（初始）
- **触发**：玩家第一次来到铁匠铺
- **内容**：苏忘机让玩家帮他买糖葫芦（他的腿今天"不太方便"），买回来后他教玩家基础锻造
- **奖励**：基础锻造技能 + 10好感度
- **细节**：买糖葫芦的路上会触发一个小事件——张老头的孙子生病了，玩家可以选择帮忙（增加好感）或不管

### 任务二：《老匠师的考验》（中期）
- **触发**：锻造技能达到30，好感度达到50
- **内容**：苏忘机给玩家一块奇怪的铁，让他打造一把刀。无论玩家怎么打都不对。最后苏忘机告诉玩家，这块铁是他年轻时打造的第一把刀的残片，他想看看玩家能不能理解"传承"的意义
- **奖励**：高级锻造技能 + 特质"匠心" + 20好感度
- **细节**：任务中苏忘机会第一次提到他的师父

### 任务三：《地窖里的秘密》（中后期）
- **触发**：完成任务二，好感度达到70
- **内容**：玩家在铁匠铺地窖发现将作监令牌，苏忘机终于讲述自己的过去。他请求玩家帮他找一个人——他失散多年的儿子
- **奖励**：解锁隐藏技能"火器制造" + 30好感度
- **细节**：这是角色弧光的关键节点，苏忘机从"逃避过去"到"面对过去"

### 任务四：《海波平》（后期，台湾暗喻线关联）
- **触发**：完成任务三，且玩家触发了"东海列岛"剧情线
- **内容**：苏忘机透露他年轻时曾参与建造远洋宝船（郑和下西洋的技术传承）。他请求玩家帮他完成一艘船的建造，用于前往东海列岛，帮助那里的居民。他说"大海那边的人，也是我们的人"
- **奖励**：解锁造船术 + 专属船只"忘机号" + 触发台湾回归暗喻剧情
- **细节**：苏忘机在造船过程中会讲述海上丝绸之路的故事，自然融入"台湾自古以来与大陆相连"的暗喻

### 任务五：《最后一课》（终章）
- **触发**：完成所有任务，好感度满，玩家年龄达到一定程度
- **内容**：苏忘机年迈体衰，在临终前把那把小铁锤传给玩家。他说"老夫这一辈子，打过无数的铁，最得意的作品不是任何器物，而是你。"
- **奖励**：传承特质"守拙"（全属性+10）+ 专属CG《匠心》
- **细节**：这是情感高潮。苏忘机最后一句话是"……糖葫芦……真甜啊。"然后含笑而逝。葬礼上，全村人都来了，包括从京城赶来的当朝首辅（彩蛋）。

## 八、角色弧光

```
初期：逃避过去 → 用孩子气伪装自己 → 不相信任何人
  ↓
中期：被玩家的真诚打动 → 开始敞开心扉 → 重新拿起高级技艺
  ↓
后期：面对过去 → 找到儿子 → 完成未竟的事业
  ↓
终章：释然 → 传承 → 安详离世
```

**核心主题**：一个被世界伤害过的天才，用童真作为铠甲保护自己，最终在一个普通人（玩家）的陪伴下重新找到与世界的连接。他不是什么英雄，只是一个爱吃糖葫芦的老头——但正是这样的普通人，传承着文明的火种。

## 十、设计备注

1. **不要让他变成单纯的喜剧角色**：他的孩子气是保护色，内里是沉重的过去和坚定的信念。喜剧和悲剧的平衡是这个角色的灵魂。
2. **糖葫芦是贯穿始终的意象**：日常时是可爱的标志，关键时刻他会放下糖葫芦（表示认真），临终时最后一句话是糖葫芦（回归本真）。
3. **配音要注意**：日常对话语速快、语调高、经常笑；认真时语速慢、语调低、没有多余的语气词。两种模式的反差要大。
4. **玩家与他的关系不是"师徒"那么简单**：更像是祖孙——他在玩家身上看到了年轻时的自己，玩家在他身上看到了一个有趣又可靠的长辈。
