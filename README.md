# 山河纪元 · ShanHe Era

> 历史不是背景。历史就是世界本身。
> 天下不会等待一个英雄出现。亿万普通人的选择，共同组成时代。
> 玩家不是被选中的人。玩家只是出生在华夏大地上的一个生命。

**华夏古代历史文明沙盘 RPG / 历史沙盒RPG**


---

## 特性

### 核心玩法
- **超高自由度人生模拟**：从农民到皇帝，从工匠到名将，每一条人生道路都完整可玩
- **世界不围绕玩家运行**：NPC拥有独立的家庭、目标、利益、性格、命运，自行生活
- **九大文明支柱**：朝廷、士人、宗族、农业、商业、工匠、军事、江湖、民间文化
- **动态历史演化**：朝代更迭、改革变法、天灾疫病、战争起义——历史不会停止
- **多代传承**：玩家死亡后可继续扮演后代，家族兴衰由你书写

### 视听体验
- **动态背景音乐**：太平、紧张、战争、史诗、悲壮、凯旋等多种情绪配乐
- **历史时刻CG动画**：开国、战争、统一、宝岛归心等关键时刻触发动画
- **三语支持**：中文 / English / 日本語

---

## 技术栈

- **引擎**：Unreal Engine 5.3+
- **语言**：C++20
- **UI**：Unreal Motion Graphics (UMG)
- **音频**：MetaSounds + 动态音乐系统
- **本地化**：UE5 本地化仪表板（PO 格式）
- **启动器**：Python + tkinter（可打包为 exe）

## 编译与运行

### 前置要求
1. **虚幻引擎5.3或更高版本**（通过Epic Games Launcher安装）
2. **Visual Studio 2022或2026**（含C++游戏开发工作负载）
3. **Windows 10/11 64位**

### 编译步骤
1.右键点击ShanHeEra.uproject`，选择生成 Visual Studio 项目文件**
2. 打开生成的 `ShanHeEra.sln`
3. 配置选择 **Development Editor | Win64**
4. 按 **F5** 或点击 **本地Windows调试器** 编译并运行
5. 首次编译可能需要5-15分钟

### 打包发布
1. 在UE5编辑器中打开项目
2. 菜单 **平台 → Windows → 打包项目**
3. 选择输出目录
4. 打包完成后，将 `Launcher/launcher.py` 配置为指向打包后的exe

### 启动器
```bash
cd Launcher
python launcher.py
```
打包为exe：
```bash
cd Launcher
build_exe.bat
```

## 设计理念

本游戏基于《山河纪元·华夏古代人生模拟器》设计文档（120+章），核心原则：

1. **玩家不是救世主**——你只是一个普通人，历史不会强行给予机会
2. **世界自动运行**——即使你不参与，历史依然前进
3. **身份不是命运**——农民可以通过读书、经商、军功改变人生
4. **没有绝对善恶**——官员可能是清官也可能是贪官，起义可能有不同目标
5. **日常即人生**——买菜、做饭、赶集、过节、访友，大量人生发生在日常中
